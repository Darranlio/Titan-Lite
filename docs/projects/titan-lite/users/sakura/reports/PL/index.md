## 1. 🔍 公司业务 DNA
::: info Planet Labs PBC
Planet Labs PBC 主要从事卫星星座的设计、建造与发射，旨在通过在线平台向美国及国际客户提供高频次地理空间数据。该公司推出的SuperDove卫星可构建地球持续在线扫描系统，目标是以最高3.5米地面采样距离（GSD）分辨率实现每日全球成像，并将行星监测数据与公共卫星数据计划中的其他科学级辐射测量数据相结合；其SkySat与Pelican卫星则通过应用程序编程接口（API）驱动，每日多次捕获指定地点影像，经处理后GSD分辨率可达50厘米。此外，Tanager高光谱成像卫星可提供覆盖可见光至短波红外区域的全谱段影像；地球观测平台则允许客户与合作伙伴通过API及浏览器应用，利用定制化解决方案或GIS工作流，发现影像任务能力、相关数据层，提取有效信息并获取洞察，从而访问、分析其专有数据目录并采取行动。该公司还提供卫星服务方案，包括客户自有卫星的设计制造、任务系统工程、发射采购、地面站基础设施、卫星运维，以及公司或客户卫星上的专属影像任务能力。其服务对象涵盖农业、测绘、能源、林业、金融、保险企业及政府机构。Planet Labs PBC成立于2010年，总部位于加利福尼亚州旧金山。
:::
