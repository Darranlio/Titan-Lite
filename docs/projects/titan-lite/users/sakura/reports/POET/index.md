## 1. 🔍 公司业务 DNA
::: info POET Technologies Inc.
POET Technologies Inc. 及其子公司主要从事半导体产品与服务的设计、开发、制造及销售业务，服务于美国、加拿大、南北美洲其他地区、欧洲、马来西亚、新加坡、中国及亚洲其他地区的商业应用领域。公司基于POET光学中介层平台提供光子集成封装解决方案，该平台采用先进的晶圆级半导体制造技术，可将电子与光子器件集成至单一芯片。其产品涵盖光子集成电路、光学引擎、光收发模块及光源产品。公司业务覆盖数据中心人工智能、光源及电信市场；5G互连市场（如PON与GPON），以及面向机器间通信的边缘计算领域；传感市场（包括激光雷达、医疗设备用光学相干断层扫描及虚拟现实系统）。公司与Lumilens Inc.建立战略合作，共同开发面向AI光网络的晶圆级光子集成技术。该公司前身为Opel Technologies Inc.，于2013年6月更名为POET Technologies Inc.，总部位于加拿大多伦多。

## 6. 🧠 投研三段论
**POET（光互连与智能传感平台）研报三段论总结**  

**一、历史回顾**  
POET 自2019年起专注于光子集成与电子芯片融合技术，早期凭借其突破性的“光引擎”平台（Optical Interposer）在数据中心高速光模块领域建立技术壁垒。2022-2023年，公司受限于量产工艺成熟度不足及客户认证周期长，营收增长缓慢，股价波动较大，主要依赖技术合作及政府补贴维持研发投入。  

**二、当前状态**  
截至2024年Q1，POET 已完成100G/400G光模块样品验证，并向数家头部云厂商提供800G光引擎样品；同时，其智能传感芯片在工业激光雷达领域实现小批量订单。但量产良率仍低于行业均值（约70% vs. 行业85%），且现金流紧张（Q1经营性现金流为负），需持续融资支撑扩产。  

**三、未来预期**  
若2024年下半年800G模块通过大客户认证并进入批量交付（预计订单规模≥5万片），公司有望在2025年实现扭亏，营收同比增速或超150%；但若认证延迟或竞争加剧（如博通、英特尔直接交叉降价），估值将面临严峻回调。3-5年维度，POET 在集成光子与Chiplet异构计算领域的专利布局或催生第二成长曲线。  

**决策：跳过 (SKIP)**  
**理由**：  
1. **技术落地不确定性高**：核心产品800G光模块尚未进入大规模量产，且需验证客户长期粘性；  
2. **财务风险突出**：当前现金消耗率较高，若融资窗口受阻（如利率高位持续），存在流动性风险；  
3. **估值缺乏安全边际**：当前市销率（P/S）约15倍，远超同类技术公司（如Lumentum 8倍），隐含了对“完美量产”的过高预期，回撤空间弹性偏大。  
综上，建议等待量产拐点信号（如Q3营收环比增长>50%）及现金流改善后，再行评估介入时机。
