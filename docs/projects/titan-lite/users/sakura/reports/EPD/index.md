# 🚀 EPD 投研价值看板

## 1. 🔍 公司业务 DNA
::: info Enterprise Products Partners L.P.
Enterprise Products Partners L.P. 为天然气、天然气凝液（NGL）、原油、石化产品及成品油的生产商与消费者提供中游能源服务。公司业务分为四大板块：天然气凝液管道与服务、原油管道与服务、天然气管道与服务、以及石化与成品油服务。其中，天然气凝液管道与服务板块涵盖天然气加工及相关NGL营销活动，运营设施包括位于科罗拉多州、路易斯安那州、密西西比州、新墨西哥州、得克萨斯州及怀俄明州的天然气加工厂、NGL管道、NGL分馏设施、NGL及相关产品储存设施，以及NGL海运码头。原油管道与服务板块运营原油管道、原油储存设施及海运码头，并拥有约200辆用于原油运输的牵引式罐车车队，同时开展原油营销业务。天然气管道与服务板块运营天然气管道系统，从事天然气的收集、处理与运输；租赁路易斯安那州拿破仑维尔的地下盐穴天然气储存设施，拥有得克萨斯州沃顿县的地下盐穴储气库，并提供天然气运输、储存及营销服务。石化与成品油服务板块运营丙烯分馏设施（包括丙烯分馏装置及丙烷脱氢装置）及相关营销业务，丁烷异构化联合装置及相关脱异丁烷装置，以及辛烷值提升、异丁烷脱氢及高纯度异丁烯生产设施。此外，该板块还运营成品油管道与终端、乙烯出口终端，并提供成品油营销及海运服务。该公司成立于1968年，总部位于得克萨斯州休斯顿。

## 6. 🧠 投研三段论
**EPD（Enterprise Products Partners L.P.）研报三段论总结**

**一、历史回顾：稳健成长的行业基石**  
过去十年，EPD凭借其一体化的中游资产布局（天然气液、原油、成品油及化工品管道与终端网络），持续实现稳定的自由现金流与分红增长。公司通过周期性并购与有机扩张，在2020年疫情低油价期间仍维持了投资级信用评级，展现了卓越的防御性。

**二、当前状态：高分红与高覆盖率的双重韧性**  
当前EPD运营现金流覆盖分配倍数长期维持在1.6倍以上，债务结构优化（杠杆率约3.2倍），且NGL出口终端项目（如Neches港）利用率处于高位。尽管面临天然气价格波动及利率压力，其合约化收入占比超80%，有效缓冲了短期市场波动。

**三、未来预期：受益于结构性增长与股东回报强化**  
中期来看，美国NGL产量增长（受益于Permian与Marcellus产区）及全球LPG/乙烷出口需求扩张，将直接拉动EPD管道与出口终端吞吐量。此外，管理层承诺每年提高分配率3%-5%，并持续回购单位，预计2025年DCF（可分配现金流）收益率将维持7%以上，在降息周期中估值修复空间明确。
