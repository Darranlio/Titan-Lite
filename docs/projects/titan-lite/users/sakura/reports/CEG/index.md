## 6. 🧠 投研三段论
**CEG研报三段论总结**

**历史回顾**  
CEG（Constellation Energy）作为美国领先的核能及清洁能源运营商，凭借其零碳核电资产组合，在能源转型初期便占据战略高地。过去五年间，公司通过资产优化与长期购电协议（PPA）锁定收益，抵御了传统电力市场的波动，同时受益于美国《通胀削减法案》（IRA）对核能税收抵免的政策红利，实现稳定的现金流增长。

**当前状态**  
当前，CEG在AI及数据中心电力需求激增的背景下，成为“算力+能源”稀缺标的。公司通过直供协议与科技巨头绑定，核电机组利用率维持高位（超95%），且电价议价能力显著提升。但短期面临核燃料成本上行（铀价自2023年涨幅超50%）及监管重审部分电站许可证的潜在风险，盈利增速承压。

**未来预期**  
预计2025-2027年，CEG将受益于以下催化剂：  
1. **核电复苏政策**：美国SMR（小型模块化反应堆）商业化部署提速，叠加IRA碳税抵扣细则落地，公司有望获增量补贴；  
2. **数据中心合约扩容**：中期内与超大规模云服务商（如微软、亚马逊）的20年以上PPA续签，锁定稳定超200亿美元营收；  
3. **股东回报提升**：自由现金流充裕（2024年预计达35亿美元），支持股息年增10%+及回购计划。  

**决策观察（WATCH）理由**  
**列入“观察”**（非立即买入/卖出），基于以下平衡：  
- **正向信号**：核电资产在AI算力泡沫中的稀缺性强化，政策明确性与合约稳定性构成防御性护城河；  
- **风险敞口**：铀价波动侵蚀毛利率（核电运营成本占比约25%），且SMR技术商业化进度（预计2028年前无法大规模落地）存在延宕可能；  
- **估值合理性**：当前PE约22倍（2024E）已部分反映定价溢价，需观察Q2电力市场交易价格（PJM容量拍卖结果）及美联储降息节奏对贴现率的联动影响。  

**结论**：核心逻辑成立但估值待验证，建议在政策落地节点（如IRA细则公示）与PJM拍卖结果披露后，再判断是否纳入配置。
