### 📚 术语表  
- <a id="term-inflation"></a>**通胀**: 物价持续上涨导致货币购买力下降的现象，直接影响央行利率决策。  
- <a id="term-rate"></a>**利率**: 资金借贷的成本，加息抑制通胀但压制资产价格，降息则反之。  
- <a id="term-tech"></a>**科技**: 指信息技术、互联网、半导体等高成长行业，通常对利率敏感。  
- <a id="term-correction"></a>**技术性修正**: 指数或股票价格从近期高点回落超过10%但低于20%。  
- <a id="term-value-trap"></a>**估值陷阱**: 看似便宜（低市盈率）但失去增长潜力或资产有毒的股票。  
- <a id="term-nasdaq100"></a>**纳斯达克100**: 纳斯达克交易所中100家最大非金融公司组成的指数，集中科技股。  
- <a id="term-ai"></a>**AI**: 人工智能技术，当前市场主线概念，直接驱动NVDA等半导体需求。  
- <a id="term-hsi"></a>**恒生指数**: 香港交易所主要股票市场指数，覆盖金融、科技等行业。  
- <a id="term-china"></a>**中国**: 此处指中国大陆的宏观经济、政策与A股市场。  
- <a id="term-csi300"></a>**沪深300**: 沪深证券交易所中市值最大、流动性最好的300只股票，代表A股大盘风格。  
- <a id="term-hk-stock"></a>**港股**: 在香港联合交易所上市的股票（含H股、红筹股等）。  
- <a id="term-tencent"></a>**0700.HK/腾讯**: 代码0700.HK为腾讯控股的港交所代码，属于恒生科技核心成分股。  
- <a id="term-pe"></a>**市盈率**: 股价与每股收益的比率，高估或低估的常用指标。  
- <a id="term-index"></a>**指数**: 反映股票市场整体或特定板块表现的统计指标。  
- <a id="term-hk-tech"></a>**恒生科技**: 追踪香港上市的30家最大科技公司的指数。  
- <a id="term-semiconductor"></a>**半导体**: 电子芯片制造行业，NVDA的核心业务领域。
