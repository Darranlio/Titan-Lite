### 📚 金融百科 & 术语解释

- <a id="term-roe"></a>**净资产收益率 (ROE)**: 简单说就是“股东每投一块钱，公司一年能赚回多少钱”。这个数字越高，说明公司的赚钱效率越高，是个很硬核的指标。
- <a id="term-pe"></a>**市盈率 (PE)**: 衡量“你买这家公司，多少年能回本”。一个数字是20倍，意味着假设利润不变，你需要20年才能收回投资。PE低不代表便宜，PE高也不代表贵，需要结合公司的增长速度来看。
- <a id="term-davis-double-kill"></a>**戴维斯双击**: 是投资者最想看到的情景。指的是：公司盈利上涨，推动股价上涨；同时，投资者因为看好公司前景，愿意给出更高的估值（市盈利），再次推动股价上涨。两者叠加，股价会暴涨。
- <a id="term-davis-double-kill-alt"></a>**戴维斯双杀**: 是戴维斯双击的反面。指公司盈利下滑，股价下跌；同时，投资者对公司失望，给出的估值也降低，导致股价暴跌。是价值投资的噩梦。
- <a id="term-peg"></a>**PEG (市盈率相对盈利增长比率)**: 就是用市盈率除以公司的盈利增长率。一般认为PEG=1是合理的估值。如果PEG远大于1，说明股票可能被高估了。
- <a id="term-support-level"></a>**支撑位**: 股票价格下跌时，容易“撑住”开始反弹的价位。可以理解为市场上有很多人愿意在这个价格买入，形成了无形的“地板”。
- <a id="term-death-cross"></a>**死叉**: 技术分析中，短期均线（如10日线）向下穿越长期均线（如20日线），通常被视为卖出信号，意味着短期趋势走弱。
