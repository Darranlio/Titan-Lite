### 📚 金融百科 & 术语解释

*   <a id="term-戴维斯双击"></a>**戴维斯双击**: 指一家公司的**盈利增长**（每股收益EPS提升）和**市场估值**（市盈率PE）同时提高，导致股价出现超额涨幅。比如，一家公司因业绩好，赚钱变多了（EPS增长），同时市场觉得它前景好，愿意给更高的倍数（PE增长），股价就会“双击”向上。
*   <a id="term-多头排列"></a>**多头排列**: 技术分析术语，指短期均线（如5日线）上穿中期均线（如20日线），中期均线上穿长期均线（如60日线），形成多头向上发散的形态，代表趋势看涨。
*   <a id="term-价值陷阱"></a>**价值陷阱**: 指一只股票看起来很便宜（比如市盈率PE很低），但实际上是因为其业务正在恶化（如亏损、市场份额流失、技术被淘汰），导致未来盈利能力持续下降，低估值是假象，投资者买入后反而可能遭受损失。
*   <a id="term-美元指数"></a>**美元指数**: 衡量美元兑一篮子主要货币（欧元、日元、英镑等）汇率变化的指标。美元走强，通常不利于新兴市场股市和以美元计价的大宗商品；美元走弱，则利好新兴市场资产和全球风险偏好回升。
*   <a id="term-核心资产"></a>**核心资产**: 通常指在行业内具有强大品牌、技术或资源优势（即“护城河”）、盈利能力稳定（高ROE）、且增长前景确定的优质龙头公司股票，被认为是投资组合中的“压舱石”。
*   <a id="term-护城河"></a>**护城河**: 指一家公司能够长期抵御竞争对手的结构性优势，例如品牌（茅台）、网络效应（腾讯）、技术壁垒（英伟达）、成本优势等，使其能维持高利润率。
