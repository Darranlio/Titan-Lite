### 📚 金融百科 & 术语解释

- <a id="term-id"></a>**戴维斯双击**: 一家公司的**每股盈利（EPS）**增长，同时市场给它的**市盈率（PE）**也变高了，股价就会涨得很快。就像被按了两次加速按钮。
- <a id="term-id"></a>**多头排列**: 在股票K线图上，短期均线（如5日线）在中期均线（20日线）之上，中期均线又在长期均线（60日线）之上，形成向上散开的状态，就像一排楼梯往上走，代表股价处于强势上涨趋势。
- <a id="term-id"></a>**RSI背离**: 股价创了新高，但**相对强弱指标（RSI）**反而没创新高，这叫**顶背离**，是股价可能要跌的信号。反之，股价创新低但RSI不创新低，叫**底背离**，是可能要涨的信号。
- <a id="term-id"></a>**MACD**: 一种技术指标，用来衡量股价上涨或下跌的动能。当快线（DIF）从下往上穿过慢线（DEA），叫**金叉**，通常看涨。从上面穿过，叫**死叉**，通常看跌。
- <a id="term-id"></a>**CDS (信用违约互换)**: 有点像给债券买的“保险”。如果债券违约（还不上钱），买了CDS的人就能得到赔偿。所以CDS的价格（保费）越高，说明市场觉得这家公司或国家违约的风险越大。
- <a id="term-id"></a>**价值陷阱**: 有些公司看起来股票很便宜（市盈率很低），但这通常是因为它的业务出了问题，比如夕阳产业、利润连年下滑。投资者买进去会发现股价一直不涨，甚至越跌越便宜，这就是陷阱。
- <a id="term-id"></a>**均值回归**: 就像一个钟摆，荡得太高了（贵了）总会落回来，荡得太低了（便宜了）总会弹回去。股价也一样，涨多了会跌，跌多了会涨，最终会回到其内在价值附近。
