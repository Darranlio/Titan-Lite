## 1. 🔍 公司业务 DNA
::: info Snowflake Inc.
Snowflake Inc. 为美国及全球各类组织提供基于云的数据平台。其平台包含人工智能（AI）数据云，使客户能够将数据整合至单一可信源，从而驱动有意义的业务洞察、构建数据应用、共享数据及数据产品，并运用AI解决业务问题。公司服务于金融服务、广告、媒体与娱乐、零售与消费品、医疗与生命科学、制造业、科技、电信、旅游与酒店、政府与国防等行业，以及公共部门。此外，公司与OpenAI L.L.C.合作，为联合企业客户开发可带来切实投资回报的AI解决方案。该公司前身为Snowflake Computing, Inc.，于2019年4月更名为Snowflake Inc.。Snowflake Inc.成立于2012年，总部位于加利福尼亚州门洛帕克。

## 6. 🧠 投研三段论
**历史回顾**  
Snowflake（SNOW）自2020年上市以来，凭借云原生数据仓库与数据湖的整合架构，在云计算高速渗透期实现爆发式增长，营收年复合增长率超100%。但2022年后，伴随宏观利率上升与科技股估值修正，其高倍数估值大幅回调，叠加客户支出谨慎与竞争加剧（如Databricks、云厂商原生服务），增速显著放缓，股价下跌超过70%。

**当前状态**  
SNOW仍处于产品周期扩张期，最新季度营收同比增长32%，但净扩张率降至128%（低于历史峰值），反映存量客户增购放缓。公司通过推出AI/ML功能（如Snowpark、Cortex）与跨云数据协作场景提升粘性，但尚未转化为显著的收入加速。自由现金流利润率已转正至约10%，盈利能力改善，但PS估值仍高于10倍，市场对降速与盈利平衡持审慎态度。

**未来预期**  
中期看，AI原生数据应用需求将驱动数据平台需求，SNOW的弹性计费模式与多云能力或受益于企业云迁移深化。但竞争红海化（尤其是开源替代与降价压力）及客户成本优化趋势可能压制收入增速至20%以下。长期盈利拐点可期，但需验证其能否通过高附加值产品（如AI推理、合规数据共享）打开第二增长曲线。

**Hold 理由**  
当前SNOW处于“估值消化”与“新产品验证”的过渡期：短期缺乏明确催化（收入增速放缓、竞争加剧），但中长线具备数据基础设施领域的战略价值与AI场景的期权属性。因此建议Hold，避免追涨杀跌：若股价回调至合理估值区间（如PS < 8x）或AI功能转化超预期，可择机增持；否则继续观望其盈利改善与增长拐点信号。
