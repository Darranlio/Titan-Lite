## 1. 🔍 公司业务 DNA
::: info Apple Inc.
苹果公司（Apple Inc.）在全球范围内设计、制造并销售智能手机、个人电脑、平板电脑、可穿戴设备及配件。其产品线包括：iPhone系列智能手机、Mac系列个人电脑、iPad系列多功能平板电脑，以及可穿戴设备、家居与配件（涵盖AirPods、Apple Vision Pro、Apple TV、Apple Watch、Beats产品、HomePod，以及苹果品牌及第三方配件）。此外，公司提供AppleCare支持服务与云服务，并运营包括App Store在内的多个平台，使用户能够发现并下载应用程序及数字内容（如书籍、音乐、视频、游戏、播客等），同时提供广告服务（包括第三方授权安排及自有广告平台）。公司还推出多种订阅制服务，例如：游戏订阅服务Apple Arcade、个性化健身服务Apple Fitness+、提供精选收听体验及点播电台的Apple Music、新闻与杂志订阅服务Apple News+、独家原创内容及体育赛事直播的Apple TV、联名信用卡Apple Card、无现金支付服务Apple Pay，并开展知识产权授权业务。其客户涵盖消费者、中小企业，以及教育、企业和政府市场。公司通过App Store为其产品分发第三方应用程序，并通过零售店、在线商店、直销团队，以及第三方蜂窝网络运营商与经销商销售产品。该公司前身为Apple Computer, Inc.，于2007年1月更名为Apple Inc.。苹果公司成立于1976年，总部位于加利福尼亚州库比蒂诺。
:::

## 6. 🧠 投研三段论
**历史回顾**：苹果（AAPL）长期受益于iPhone超级周期与生态护城河（App Store、iCloud等），硬件+服务双轮驱动业绩稳健增长。但近年面临创新趋缓与监管压力，估值由扩张回归理性区间。

**当前状态**：财报显示服务收入创历史新高，iPhone在高端市场仍具韧性，但硬件销量增速放缓，AI布局（Apple Intelligence）尚未形成实质性收入。市场博弈“确定性溢价”与“增长瓶颈”，PE处于30x附近，略高于五年中位数。

**未来预期**：AI端侧落地（如Siri重构、AR/VR生态）或打开新增长曲线，但增量贡献需至2026年才能兑现；同时全球消费电子需求疲软、中国市场竞争加剧（华为回归）构成短期逆风。机构预期未来两年营收增速维持低个位数。

**持有多仓（Hold）理由**：当前估值未充分计入AI长期潜力，但缺乏短期催化突破前高，下行风险（地缘政治、反垄断）与上行收益（AI+服务提价）大致均衡，属于“合理价格持有优质资产”。建议保留仓位，观察苹果智能（Apple Intelligence）对换机周期的实质拉动效果。
