# 🚀 LUNR 投研价值看板

## 1. 🔍 公司业务 DNA
::: info Intuitive Machines, Inc.
Intuitive Machines, Inc. 是一家总部位于美国的太空基础设施与服务公司。该公司主要提供以下业务：有效载荷运输与交付服务，包括将卫星、科学仪器及货物等运送至太空中的不同目的地，并提供拼单发射及月球表面进入服务；数据传输服务，涵盖天基数据的采集、处理与解读，以及利用人工智能应用执行指挥、控制、通信、侦察与勘探等任务；以及面向导航、维护、科学数据采集及系统健康监测的基础设施即服务解决方案。此外，公司还提供Nova-C月球着陆器，该产品融合了经过飞行验证的技术与可扩展设计，以满足新兴月球经济的需求；Micro Nova Hopper则开发了一种推进式无人机，设计用于在其IM-2任务中完成着陆、部署与跳跃；Nova-D则用于运输关键有效载荷，包括提供裂变表面能源系统、月球地形车及月球车等基础设施服务，以支持可持续的月球探索与开发。公司还提供月球数据网络服务。其客户包括美国政府机构（如NASA、国家安全太空部门、美国国防部及州政府）、商业客户及国际客户。该公司成立于2013年，总部位于得克萨斯州休斯顿。
:::

## 6. 🧠 投研三段论
基于对LUNR（Intuitive Machines）近期业务动态及市场表现的分析，以下为三段论总结及决策“跳过（SKIP）”的理由：

**历史回顾**  
LUNR作为商业月球探测领域的先行者，凭借IM-1任务实现美国50年来首次月面软着陆，验证了其“Nova-C”着陆器技术。然而，任务中因导航激光测距仪故障及着陆姿态异常，暴露了关键系统可靠性不足，导致股价剧烈波动，投资者信心受挫。

**当前状态**  
公司正推进IM-2与IM-3任务，并与NASA签订价值超30亿美元的“月球通信与导航服务”合同。但2024年Q2财报显示运营现金流仍为负，且近期因再融资稀释股本，股价承压。技术层面，着陆器着陆精度与冗余设计尚未完全验证，而SpaceX等对手的竞争威胁持续存在。

**未来预期**  
若后续任务成功，LUNR有望在商业月球载荷运输、数据中继（如4G/5G）及资源勘探（如极地水冰）领域建立壁垒，NASA持续买单将提供收入下限。但任务失败风险、稀释性融资需求及商业化周期过长（预计2026年后才有稳定回报），使短期股本回报率高度不确定。

**决策：跳过（SKIP）**  
**核心理由**：当前估值已部分透支后续任务的成功概率（市净率超4倍），但技术验证尚未完成，且再融资稀释与财务亏损并存。在IM-2任务获得明确结果前，股价更多受事件投机驱动而非盈利支撑。建议跳过，等待着陆器可靠性及现金流改善的实质性证据。
