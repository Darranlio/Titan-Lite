风险警示：别为“情怀”买单 💸

1. **估值泡沫风险**：一个没有盈利、甚至没有稳定营收的公司，其股价的任何上涨，都可能是在透支未来。当资金退潮，谁在裸泳一目了然。
2. **基本面恶化风险**：负ROE意味着股东权益在持续受损。如果公司无法在可预见的未来实现盈利，其股价将面临回归基本面的巨大压力。
3. **政策与行业风险**：太空探索是高度依赖政策和政府订单的行业。任何技术瓶颈、预算削减或竞争加剧，都可能让“登月”变成“梦碎”。

**压舱石金句**：**在资本市场上，最昂贵的三个字不是“我错了”，而是“我以为”。** 尤其是当“我以为”的背后，是虚幻的星辰大海，而非坚实的财务报表时。
