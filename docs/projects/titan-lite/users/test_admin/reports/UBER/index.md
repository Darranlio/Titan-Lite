## 1. 🔍 公司业务 DNA
::: info Uber Technologies, Inc.
Uber Technologies, Inc. 在美国、加拿大、拉丁美洲、欧洲、中东、非洲及亚太地区开发并运营自有技术应用程序。该公司通过三大业务板块运营：出行（Mobility）、配送（Delivery）和货运（Freight）。出行板块连接消费者与多种交通方式，包括拼车、汽车共享、微出行、租赁、公共交通、出租车及其他模式；为乘客提供多种车型选择，并涵盖金融合作产品及广告服务。配送板块使消费者能够搜索并发现餐厅、生鲜、酒类、便利店及其他零售商，订购餐食或其他商品，可选择到店自取或配送上门；同时提供Uber Direct（面向零售商及餐厅的白标配送即服务平台）及广告服务。货运板块管理运输与物流网络，通过数字市场连接托运方与承运方，涵盖承运方预付款、定价及货运预订；并为中小企业至全球企业提供按需平台，实现端到端物流交易的自动化。该公司前身为Ubercab, Inc.，于2011年2月更名为Uber Technologies, Inc.。Uber Technologies, Inc.成立于2009年，总部位于加利福尼亚州旧金山。
:::

## 6. 🧠 投研三段论
以下是为 UBER 研报所做的三段论总结与 Hold 评级理由，力求专业、精炼：

**一、历史回顾**  
自2009年创立以来，Uber 经历了从共享出行颠覆者到全球出行+配送平台龙头的演变。2019年IPO后，受疫情冲击订单腰斩，但通过成本优化与业务重组（如出售自动驾驶部门、聚焦核心市场），实现从“亏损扩张”向“盈利导向”转型。2020-2022年，外卖业务（Uber Eats）与出行需求恢复形成双轮驱动，驱动收入与利润显著改善。

**二、当前状态**  
Uber 已实现GAAP盈利，2024年Q3营收超100亿美元，同比增长20%；出行、配送、货运三大板块均正增长。移动出行市场份额稳固（美国超70%），配送业务持续跑赢行业（市占率约30%）。但面临监管（加州AB5法案、欧盟司机身份争议）、保险/司机成本上行、Lyft/X竞对压力等逆风。自由现金流为正，资产负债表改善（净债务降至历史低位）。

**三、未来预期**  
中期关键增量来自：①自动驾驶技术落地（合作Waymo/Motional）降低司机成本中枢；②广告平台（Uber Ads）变现率高毛利；③国际渗透（拉美、印度、东南亚）与会员粘性提升。长期风险：自动驾驶出行若驱动价格战，或伤害平台抽佣率；经济衰退或压缩可支配出行/外卖支出。市场共识预计2025-2026年营收CAGR约12-15%，EBITDA利润率升至中高双位数。

**四、Hold 评级理由**  
1. **风险收益均衡**：当前估值（~35x 2025E P/E）已反映盈利改善与自动驾驶催化，但尚未充分计入监管与竞争不确定性。上行空间有限（目标价约7-10%），下行保护尚可（现金流、网络效应强）。  
2. **缺乏明确催化剂**：自动驾驶商业化进度慢于乐观预期，传统业务增长趋稳，短期难见盈利跳升或估值重估事件。  
3. **仓位管理价值**：对持有者而言，放弃将损失确定性股息或回购替代收益（无股息），但卖出可能错过长期无人驾驶场景期权。维持持有，等待更清晰信号（如Lyft异常折价、监管明朗）后再做增减。
