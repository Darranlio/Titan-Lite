## 6. 🧠 投研三段论
**历史回顾**  
MP（算力/芯片领域）自2020年以来经历了两轮显著周期：2021年受全球芯片短缺与AI算力需求爆发推动，股价与估值快速攀升；2022年受美联储加息、下游资本开支放缓影响，估值大幅回调，但技术路线（异构计算、Chiplet）的领先地位得到验证。

**当前状态**  
公司处于“去库存尾声+新品导入期”的过渡阶段。2024Q3营收同比微降但环比改善，毛利率受制于成熟制程竞争。市场对下一代架构（如MCM-GPU）的预期较高，但短期业绩指引保守，叠加宏观经济不确定性，估值修复节奏缓慢。

**未来预期**  
若2025年数据中心资本开支回暖，叠加自研平台导入量产，MP有望在H2实现营收同比增速回升至20%+。但需关注英伟达生态挤压及客户自研芯片替代风险，长期成长性需依赖技术护城河的实质性突破。
