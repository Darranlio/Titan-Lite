## 1. 🔍 公司业务 DNA
::: info NVIDIA Corporation
英伟达公司（NVIDIA Corporation）是一家以数据中心规模为运营基础的人工智能基础设施企业。公司下设两大业务板块：计算与网络板块，以及图形板块。其中，计算与网络板块提供数据中心加速计算与网络平台、人工智能解决方案及软件、汽车平台及自动驾驶与电动汽车解决方案（含软件）；图形板块则提供面向游戏及个人电脑的GeForce GPU，以及面向企业级工作站图形的Quadro/NVIDIA RTX GPU。公司产品广泛应用于游戏、专业可视化、数据中心及汽车市场。其销售对象涵盖原始设备制造商、原始设计制造商、系统集成商与分销商、独立软件供应商、云服务提供商、板卡制造商、经销商、汽车制造商及一级汽车供应商，以及全球其他生态系统参与者。英伟达已与马衡达信息技术有限公司（Tech Mahindra Limited）合作开发基于人工智能的电信网络运营推理代理；与朗美通控股公司（Lumentum Holdings Inc.）建立战略合作伙伴关系，共同开发面向人工智能及数据中心的光学技术；与Nebius Group N.V.达成战略合作，为人工智能市场构建并部署超大规模云平台；并与IREN Limited建立战略合作，加速部署高达5吉瓦的基础设施。英伟达公司成立于1993年，总部位于加利福尼亚州圣克拉拉市。
:::

## 6. 🧠 投研三段论
**历史回顾**  
英伟达（NVDA）自2022年底至2024年完成从游戏显卡向AI算力核心的转型，受益于大模型训练需求爆发，营收与利润呈指数级增长，股价累计涨幅超6倍，成为全球市值最高半导体公司。其CUDA生态与数据中心业务构筑了阶段护城河。

**当前状态**  
2024年，NVDA面临增速边际放缓与竞争加剧：Hopper系列仍占主导，但Blackwell架构延期引发部分市场担忧；AMD与定制化AI芯片（如谷歌TPU）逐步渗透；同时美国出口管制限制中国区收入潜力。估值处于历史高位，PE超40倍，隐含对2025年持续高增长的预期。

**未来预期**  
2025-2026年，AI推理需求有望接力训练驱动增长，Blackwell全面放量将强化产品力；企业级AI部署与主权AI基建提供长期空间。但需警惕采购周期向后推迟、超大规模客户自研芯片取代NVDA份额，以及地缘政治升级风险。

**Hold 决策理由**  
当前估值已部分消化乐观预期，增速放缓与竞争压力构成短期逆风，不宜追高。但AI结构性需求确定性强，NVDA技术领先与生态粘性仍支持长期盈利韧性。维持持有，待估值修复或技术拐点出现后，可重新评价加仓或减持。
