## 1. 🔍 公司业务 DNA
::: info Ondas Inc.
Ondas Inc. 在美国及国际市场提供私有无线网络、无人机及自动化数据解决方案。公司业务分为两大板块：Ondas Networks（昂达斯网络）与Ondas Autonomous Systems（昂达斯自主系统）。其产品包括：反无人机系统（CUAS）及站点防护系统，例如“铁无人机突袭者”（Iron Drone Raider）——一种用于压制小型敌对无人机的全自主拦截无人机系统；Sentrycs CoRF——基于网络/射频的反无人机平台，用于探测、识别、追踪及管控未经授权的无人机；Optimus系统——全自主无人机平台，用于持续安防、监控及关键任务数据采集；4M Defense——支持排雷及清除未爆弹药相关任务；Roboteam——无人地面车辆（UGV）及战术地面机器人；Apeiro Motion——用于机器人平台的自主与移动软件，提升导航与作战效能；以及游荡弹药系统——一种单向无人机，适用于包括情报、监视、侦察（ISR）防御及打击在内的多种任务。此外，公司还提供：FullMAX软件定义无线电平台——一种专利SDR平台，用于构建安全、私有、广域宽带网络，支持关键任务通信；软硬件维护协议——涵盖持续支持、安全升级及功能增强的延保合同；许可/版税——将FullMAX软件及技术授权集成至合作伙伴的软硬件平台；以及辅助服务——包括无线网络设计、系统工程、射频规划、软件配置、产品培训、安装、现场支持及工程/产品开发。公司客户涵盖铁路、电力公用事业、石油天然气、公共安全、政府及其他工业领域。该公司前身为Ondas Holdings Inc.，于2026年1月更名为Ondas Inc.。Ondas Inc.成立于2014年，总部位于佛罗里达州西棕榈滩。
