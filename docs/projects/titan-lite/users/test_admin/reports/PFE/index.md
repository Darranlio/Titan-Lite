# 🚀 PFE 投研价值看板

## 1. 🔍 公司业务 DNA
::: info Pfizer Inc.
辉瑞公司（Pfizer Inc.）在美国及全球范围内从事生物制药产品的发现、开发、生产、营销、分销及销售业务。公司下设三大业务板块：生物制药（Biopharma）、PC1及辉瑞 ignite（Pfizer Ignite）。其产品涵盖：内科药物，包括以艾乐妥（Eliquis）品牌为代表的心血管代谢疾病药物；以 Nurtec ODT/Vydura 及 Zavzpret 品牌为代表的偏头痛药物；以 Prevnar 系列、Abrysvo、Nimenrix、FSME/IMMUN-TicoVac 及 Trumenba 品牌为代表的疫苗；以及用于治疗 COVID-19 的 Paxlovid。此外，公司还提供炎症与免疫学药物，如 Xeljanz、Enbrel、Cibinqo、Litfulo、Eucrisa 及 Velsipity；罕见病药物，涵盖淀粉样变性、血友病及内分泌疾病等领域，品牌包括 Vyndaqel 系列、Genotropin、BeneFIX、Xyntha、Somavert、Ngenla 及 Hympavzi；以及抗感染与免疫球蛋白药物，品牌包括 Zavicefta、Octagam 及 Panzyga。在肿瘤领域，公司提供抗体偶联药物（ADC）、小分子药物、双特异性抗体及其他免疫疗法，用于治疗乳腺癌、泌尿生殖系统肿瘤、血液恶性肿瘤、黑色素瘤、胃肠道肿瘤、妇科肿瘤及肺癌等，品牌包括 Ibrance、Xtandi、Padcev、Adcetris、Inlyta、Lorbrena、Bosulif、Tukysa、Braftovi、Mektovi、Orgovyx、Elrexfio、Tivdak 及 Talzenna。此外，公司还提供以 Inflectra 品牌为代表的生物类似药；肿瘤生物类似药，包括 Retacrit、Ruxience、Zirabev、Trazimera 及 Nivestym 等；以及其他生物类似药；以及无菌注射剂，如 Sulperazon、Atgam、Fragmin、Solu Medrol、Solu Cortef 及 Bicillin。公司与百时美施贵宝公司（Bristol-Myers Squibb Company）、安斯泰来美国制药公司（Astellas Pharma US, Inc.）、默克集团（Merck KGaA）及 BioNTech SE 等建立了合作协议，并与 Boltz, PBC 达成战略合作，共同开发及部署生物分子人工智能基础模型。辉瑞公司成立于1849年，总部位于纽约州纽约市。
:::

## 6. 🧠 投研三段论
**三段论总结：辉瑞（PFE）研报核心逻辑**

**1. 历史回顾：疫情红利消退，转型阵痛显现**  
PFE在新冠疫苗Comirnaty与口服药Paxlovid驱动下，2021-2022年营收创历史峰值，但2023年起疫情相关收入骤降，叠加专利悬崖（如Eliquis、Xeljanz仿制药侵蚀），公司面临核心产品线增长断层。过去两年股价回调超40%，反映市场对后疫情时代盈利中枢下移的悲观定价。

**2. 当前状态：非新冠业务承压，管线与成本调整并行**  
2024年非新冠收入同比下滑约5%（剔除收购Seagen的贡献），肿瘤与罕见病领域增长（如ADC药物与基因疗法）尚不足以对冲成熟产品下滑。管理层启动40亿美元成本削减计划，并推进Seagen整合（目标2025年贡献50亿美元营收），但管线中仅有RSV疫苗（Abrysvo）与Pfizer/BioNTech新一代新冠-流感mRNA疫苗处于晚期临床，短期催化有限。

**3. 未来预期：估值修复依赖Seagen落地与降息周期**  
预计2025年营收重回同比增长（约580-600亿美元），Seagen整合效应及RSV疫苗放量是关键驱动力。若美联储降息改善融资环境，PFE当前估值（约10倍前瞻PE）存在修复空间，但需观察未来12个月关键数据（如ADC组合III期读出）能否扭转市场对其创新能力的质疑。

**决策观察（WATCH）理由**  
- **中性偏等待**：PFE短期缺乏业绩爆发点（2024-2025年EPS或仅同比增长3-5%），Seagen协同性需2-3年验证，且2025年FDA对“中链项目”的审批结果（如PD-L1/VEGF双抗）存在不确定性。  
- **风险收益比改善概率**：若S&P 500利空消化后，PFE可视为防御性低估标的（股息率约6%），但当前并非最佳入场节点——需等待RSV疫苗季度销售超预期或ADC管线里程碑事件触发情绪反转。  
- **结论**：**维持WATCH评级**，建议投资者待2025年Q1财报后，观察非新冠产品组合增速是否拐点确认，再行决策。
