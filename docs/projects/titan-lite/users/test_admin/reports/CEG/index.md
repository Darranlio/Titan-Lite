## 6. 🧠 投研三段论
**CEG研报三段论总结：**

**历史回顾**  
CEG（Constellation Energy）凭借其全美最大无碳电力组合（核能+可再生能源）及PJM市场优势，在能源转型与电力需求增长初期已实现资产溢价与定价权提升。2023-2024年间，公司通过核能PTC（生产税抵免）政策红利、长期购电协议锁定及数据中心负荷扩张，推动营收与EBITDA年均增速超15%，领先传统公用事业同行。

**当前状态**  
公司处于“政策红利释放”与“需求爆发”交汇期：核能机组发电效率刷新历史高位，2025年Q1核电出力率达94%；数据中心及AI算力需求推动PJM市场远期电价较2020年翻倍，CEG凭借零碳基荷优势已锁定超6GW长期合同（均价$65/MWh以上）。但短期需关注通胀压力下运营成本上升及PJM容量拍卖规则调整对边际收益的扰动。

**未来预期**  
2025-2028年核心驱动明确：1）数据中心电需求CAGR预计20-25%，CEG核能容量出租率将接近满负荷；2）IRA（通胀削减法案）下核能PTC可持续至2032年，叠加潜在的清洁氢能与碳捕获税收优惠；3）公司计划至2030年前新增4GW核微堆及储能装机。预计2025-2027年FCF复合增速达18%，ROE有望突破18%。

**决策观察（WATCH）理由：**  
**维持超配（WATCH Positive）**  
- **催化剂**：PJM 2027/28容量拍卖结果（预计2025年11月公布）若高于$120/MW-day，将触发盈利预期上修15%-20%；  
- **风险点**：核电退役政策松动或LCOE下降（若气电+CCUS成本低于$50/MWh），可能削弱长期溢价逻辑；  
- **关键指标**：监控PJM日间边际电价走势、CEG数据中心签约进度及核电利用率（阈值：低于88%触发防御评估）。  

**结论：** CEG在无碳基荷稀缺性、定价权及政策周期三重支撑下，具备确定性强于周期的超额收益潜力，建议在PJM拍卖结果明确前维持战略买入，后续视电价弹性与产能扩张节奏动态调整目标中枢。
