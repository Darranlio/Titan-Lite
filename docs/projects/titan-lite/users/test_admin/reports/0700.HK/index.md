::: info Tencent Holdings Limited

## 6. 🧠 投研三段论
**历史回顾：**  
腾讯控股（0700.HK）凭借社交生态（微信/QQ）与游戏（《王者荣耀》等）的持续变现，叠加云与金融科技业务的规模扩张，长期保持双位数收入增长。2018-2022年受行业监管收紧及宏观逆风影响，增速阶段性承压，但公司通过优化成本结构、聚焦核心业务（视频号、企业服务）恢复盈利韧性。

**当前状态：**  
2024年广告业务受益于视频号增量及AI驱动精准投放，增速领先行业；游戏业务海外占比提升（《PUBG Mobile》《Valorant》），国内版号常态化后储备丰富（《地下城与勇士》手游等）。金融科技与企业服务利润率改善，AI大模型混元赋能多场景降本增效。估值处于近五年历史低位（PE约15x），回购计划（年内超千亿港元）提供安全垫。

**未来预期：**  
游戏出海+视频号商业化+云业务AI化有望驱动2024-2026年收入/利润CAGR重回10%+。监管环境趋于稳定，资本开支向高ROE领域倾斜，叠加回购与股息提升股东回报。混元大模型若在B端形成标准化服务，或打开第二增长曲线。

**Overweight决策理由：**  
核心社交护城河未被动摇，广告、金融科技等增量引擎已清晰兑现；当前估值折价隐含过度悲观预期，盈利修复（净利润增速预计15%+）与股东回报强化（回购股息组合年化收益约3%）提供显著上行空间。综合风险收益比优异，维持超配评级。
