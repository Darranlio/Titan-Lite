## 核心投资论点

腾讯控股（0700.HK）当前处于**结构性转型与估值修复的交叉点**。我们给予**Overweight**评级，核心逻辑基于三个不可否认的事实：**资产负债表护城河（净债务/EBITDA 0.69倍）、毛利率结构性提升（2021年43%→2025年56.2%）、以及6月2日天量暴涨（1.02亿股，3倍日均量）所揭示的大资金入场信号**。

这不是一个“价值陷阱”——资产负债表和84.6%的自由现金流转化率反驳了这一点。也不是一个“即将爆发的AI巨头”——AI产品尚未定价，企业采用数据为零。它是一个**拥有巨大安全边际的结构性转型故事**，但技术面和催化剂尚未完全确认。

**关键矛盾解决：** 保守派要求“等待双底或突破50-SMA”，代价是错过早期建仓；激进派将AI货币化视为“已完成的交易”，跳过了核心假设。**Overweight是唯一逻辑一致的评级**——参与上行，同时通过分层进场和严格止损保护资本。
