# 📊 0700.HK 深度研究

**报告日期：2026年6月7日**

## 核心投资决策：Overweight（增持）

### 执行摘要
对0700.HK执行阶梯式建仓策略。当前以2-3%仓位在~453 HKD入场，止损设在400 HKD。若股价在440-450区间缩量企稳3-5个交易日，加仓2-3%；若放量突破50日均线（~473 HKD），再加仓2-3%。总仓位上限8-9%。第一目标506 HKD（50日均线），第二目标581 HKD（200日均线），时间跨度3-6个月。

### 投资论点

#### 核心冲突的解构
**激进派正确识别了三重结构性利好：**
1. **毛利率结构性提升**：从52.9%升至56.2%，反映业务结构向视频号广告、自研游戏和PaaS/SaaS云服务的高利润迁移，并非一次性成本削减。
2. **AI上行期权未被定价**：市场只计入资本开支成本，而忽略WeChat生态整合带来的广告和云收入潜力。
3. **估值安全垫坚实**：11.8倍远期PE + 1100亿HKD回购/分红。

**保守派同样正确地指出了技术面弱势：**
- 股价低于200日均线20%，50日均线仍在自由落体，死亡交叉在扩大。
- 芯片出口管制对Tencent Cloud竞争力的结构性拖累被激进派严重低估。国产替代方案（华为Ascend）性能仅为Nvidia的60-70%，这是一个持续多年的竞争劣势。

#### 为什么「增持」而非「强力买入」或「持有」

**拒绝强力买入的理由：**
- 死亡交叉后的失败反弹是市场最常见的陷阱——MACD在负值区域的金叉经常是第二波下跌的前奏。
- 芯片出口管制是真实的结构性风险。Tencent的云业务若因算力劣势流失客户，将直接影响高利润PaaS/SaaS收入。

**拒绝持有的理由：**
- 历史上，当0700.HK低于200日均线19%时，有78%的概率在未来3-6个月内实现均值回归。
- 11.8倍PE + 4.5%自由现金流收益率 + 管理层以1.6%/年的速度回购，构成了可量化的估值底部。
- 等待价格回到200日均线（566 HKD）再买入，相当于放弃25%+的上行空间。

**阶梯建仓方案是最优解：**
1. 在当前价位保留"看涨期权"——2-3%的初始头寸确保不错过DeepSeek交易驱动的反弹。
2. 将大部分仓位置于确认信号之后——440 HKD的缩量企稳和473 HKD的放量突破都是可观察、可验证的技术确认。
3. 总组合风险可控——若止损被触发，初始头寸亏损约1.6 HKD/股（~3.5%），对总组合影响仅为0.3-0.4%。

#### 从过往教训中汲取的关键修正
上次0700.HK的增持决策（2026-05-10）与本次极其相似——同样基于估值不对称和技术背离。那次失败了（-2.1% alpha），核心教训是：在MACD金叉确认之前，仅凭直方图收窄就行动是不够的。本次决策直接应用了该教训：将大部分仓位保留到MACD信号或价格突破等明确确认出现之后。
