# 🚀 ARGX 投研价值看板

## 1. 🔍 公司业务 DNA
::: info argenx SE
argenx SE 是一家处于商业化阶段的生物制药公司，专注于在美国、日本、中国、荷兰及全球其他地区开发治疗自身免疫性疾病的多款疗法。该公司已上市产品包括：用于治疗全身型重症肌无力（gMG）及免疫性血小板减少症（ITP）的VYVGART，以及用于治疗gMG和慢性炎性脱髓鞘性多发性神经病（CIDP）的VYVGART HYTRULO。在研管线方面，公司正推进efgartigimod用于治疗血清阴性gMG、眼肌型重症肌无力（MG）、原发性ITP、格雷夫斯病、肌炎、干燥综合征、系统性硬化症及抗体介导的排斥反应（AMR）；empasiprubart用于治疗多灶性运动神经病（MMN）、移植肾功能延迟恢复及CIDP；adimanebart用于治疗先天性肌无力综合征及脊髓性肌萎缩症。此外，公司还开发了ARGX-213（一种靶向新生儿Fc受体（FcRn）的工程化抗体，旨在延长半衰期并持续降低IgG水平）、ARGX-124（FcRn管线候选药物）、靶向IL-6以治疗炎症的ARGX-109、靶向免疫球蛋白A的ARGX-121，以及针对半乳糖凝集素-10的抗体药物ARGX-118，同时还包括cusatuzumab、ARGX-112、ARGX-114和ARGX-115等候选药物。公司已与再鼎医药就efgartigimod的开发和商业化达成战略合作及许可协议；与Halozyme Therapeutics就ENHANZE技术平台用于预防和治疗人类疾病开展合作；与OncoVerity, Inc就cusatuzumab达成合作；并与艾伯维（AbbVie, Inc）就ARGX-115开展合作。argenx SE成立于2008年，总部位于荷兰阿姆斯特丹。
:::

## 6. 🧠 投研三段论
基于对 ARGX（argenx SE）的全面研报分析，以下为三段论总结及跳过（SKIP）决策理由：

**历史回顾：** ARGX 凭借其核心产品 Vyvgart（efgartigimod）在全身型重症肌无力（gMG）领域实现从临床突破到商业化的跨越，成功建立了 FcRn 拮抗剂赛道的先发优势，营收快速增长，并在美国及欧洲建立直营体系。

**当前状态：** 公司正处于从单一适应症向多适应症平台扩张的关键时期。尽管 Vyvgart 在 CIDP（慢性炎性脱髓鞘性多发性神经病）适应症取得积极数据并获批，市场对其峰值销售预期已部分定价。同时，公司管线中自免领域的泛 FcRn 抑制、新生儿 Fc 受体（FcRn）及相关抗体工程化技术储备丰富。

**未来预期：** 增长驱动力取决于 CIDP 的实际处方放量速度、针对其他自免适应症（如天疱疮、ITP 等）的 III 期临床数据读出，以及后续新分子（如 SC 剂型、双抗）的临床进展。如果 CIDP 未能显著超越当前市场预期峰值（约 40-50 亿美元），公司可能面临估值天花板。

**跳过（SKIP）理由：**
1. **核心产品预期已高度兑现：** Vyvgart 在 gMG 的渗透率已趋于成熟，未来增量将高度依赖 CIDP，但该市场已有强竞争对手（如静脉注射免疫球蛋白 IVIG、补体 C5 抑制剂），商业化竞争格局激烈。
2. **管线不确定性高：** 后期管线品类的差异化尚未完全证明优于现有疗法，且多个自免适应症还处于早期阶段，未来 12-18 个月缺乏明确的催化剂事件驱动向上重估。
3. **估值保护不足：** 当前市盈率（若以非 GAAP 估算）及市销率仍隐含较高增长预期。若下一个 CIDP 季度的处方增速放缓或临床数据出现安全信号，下修风险较大。**在此节点，风险回报比不具备明显吸引力，建议跳过。**
