## 1. 🔍 公司业务 DNA
::: info Rigetti Computing, Inc.
Rigetti Computing, Inc. 通过其子公司，在美国、英国、欧洲其他地区、亚洲及国际市场，构建并运营量子计算机及超导量子处理器。该公司提供量子处理单元（QPU）及量子计算系统，并以量子计算即服务（QCaaS）的形式，通过云端提供量子计算系统的访问权限。其产品包括：Novera——一款9量子比特芯片QPU，配备可调耦合器以实现快速双量子比特操作，以及用于测试单量子比特操作的5量子比特芯片；基于第四代Ankaa级架构的Novera QPU；36量子比特的Cepheus-1-36Q多芯片量子计算机系统；以及84量子比特的Ankaa-3量子计算机。此外，公司还通过QCaaS销售其量子计算机的访问权限。同时，公司提供Rigetti量子云服务平台，支持多种编程能力、公有云或私有云集成及连接，并配备支持公有云与私有云架构的量子操作系统软件。此外，公司还提供QCS Outpost——一种用于操作、管理和监控整体系统的分布式软件环境；Rigetti Foundry Services——提供超导量子芯片以推动并加速量子信息科学与技术的研发；以及专业服务，包括算法开发、基准测试、量子应用编程及软件开发。公司客户涵盖商业企业、政府机构、国际政府实体，以及学术界、国防实验室和国家实验室。Rigetti Computing, Inc. 成立于2013年，总部位于加利福尼亚州伯克利。
:::

## 6. 🧠 投研三段论
基于对Rigetti Computing（RGTI）的专业研判，现以三段论结构总结研报核心逻辑，并阐明“跳过”的决策理由。

**历史回顾：从“量子泡沫”到市值过山车**  
RGTI于2021年通过SPAC上市，作为量子计算纯正标的曾获高估值溢价。但2022-2023年，公司面临研发进度不及预期（仅实现9量子比特芯片里程碑）、烧钱率高企（年经营现金流为负值）以及营收极低（不足千万美元），股价从高点回撤超90%。市场对其商业化路径的真实性持续存疑。

**当前状态：技术卡位但盈利无期**  
截至2024年Q2，RGTI拥有全球领先的84量子比特Ankaa系统，并与DARPA、NASA签订了部分政府合同，技术层面处于第二梯队。但公司仍处于“Pre-revenue”阶段，季度营收仅约100万美元，净利率深度亏损（-400%+）。行业面临量子纠错延迟、室温应用缺乏、及英伟达GPU对量子模拟的替代威胁。企业估值锚定于远期折现，缺乏基本面支撑。

**未来预期：高赔率与高风险并存**  
长期看，若公司能在2025-2026年实现“量子优越性”（如突破1,000逻辑量子比特）或与超导巨头绑定代工，可能引爆估值；但短期内股权稀释（2023年增发超40%）、现金跑道不足（当前现金仅能支撑约4个季度）以及竞争对手（IonQ、IBM）在离子阱、超导路线上的加速，使生存概率显著低于市场隐含的乐观预期。

**决策：跳过 (SKIP) 的理由**  
当前RGTI处于“技术叙事”与“商业现实”之间的严重错配期。1）**基本面恶化**：亏损收窄无进展，研发资本即将耗尽，大概率在2024年底前需再次稀释性融资；2）**估值泡沫**：当前PS倍数超过100倍，完全计入未来十年理想营收，一旦利率上行或风投退潮，流动性支撑即刻瓦解；3）**催化剂不确定**：量子计算距离规模化盈利至少5-7年，且公司路径依赖超导路线（易受环境干扰），相较混合量子-经典解决方案，模式单一风险显著。在未现确定性收入拐点前，等待风险回报比更优的时机是理性选择。
