## 6. 🧠 投研三段论
针对 **3690.HK（美团-W）** 的研报，以下为三段论总结与决策建议：

**历史回顾**  
美团过去三年经历了从“无限游戏”扩张（社区团购、网约车）到全面盈利导向的转折。2022-2023年，公司通过降本增效（减少亏损新业务投入、提升核心本地商业佣金与广告变现），实现净利润大幅扭亏，股价从历史低位反弹约200%，验证了经营杠杆的有效释放。

**当前状态**  
2024年至今，美团陷入“增长与竞争再平衡”：餐饮外卖与到店业务面临抖音、快手等低价平台的份额侵蚀，客单价承压；新业务（优选、快驴）仍在减亏但收入增速放缓。当前估值（约18倍2025年P/E）处于历史中位，市场对其核心业务利润率的可持续性及到店GTV增速放缓存在分歧。

**未来预期**  
短期（6-12个月），外部竞争压力未见明显缓解，且宏观消费疲软抑制客单价提升；中期需关注其“神会员”体系对到店业务的防御效果及海外（Keeta）扩张的早期信号。若竞争格局边际改善或出境业务超预期，利润率有望上修；否则可能面临增长失速与估值下修的双重压力。

**决策：跳过 (SKIP)**  
当前节点缺乏强催化：竞争格局未现拐点，资金面受南下资金波动影响，且市场对2025年利润预期已较充分定价。建议等待以下信号出现后再行介入：① 到店业务GTV增速环比企稳；② 季度利润超预期以验证防御能力；③ 海外业务亏损率收窄。在此之前，风险收益比不具吸引力。
