## 6. 🧠 投研三段论
**历史回顾**  
比亚迪股份（1211.HK）凭借新能源汽车全产业链布局与刀片电池等核心技术，从2020年起实现销量与市占率持续跃升，至2023年已成为全球新能源车销量冠军，驱动股价在2021-2022年经历显著增长，随后因行业竞争加剧及毛利率承压进入调整期。

**当前状态**  
公司2024年维持高增长态势，季度销量屡创新高，海外出口与高端品牌（仰望、腾势）贡献增量利润。但行业价格战白热化、单车盈利空间收窄，且市场对其估值溢价存在分歧，股价呈现区间震荡，技术面缺乏突破信号。

**未来预期**  
若智能驾驶技术突破、海外市场放量及成本持续优化，盈利弹性可期；但宏观需求放缓、地缘贸易壁垒及竞争对手（如特斯拉、华为系）迭代速度仍构成主要风险。管理层目标全球份额提升至20%以上，中长期成长逻辑未变。
