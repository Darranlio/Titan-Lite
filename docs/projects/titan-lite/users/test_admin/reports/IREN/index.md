## 6. 🧠 投研三段论
基于对 IREN（Iris Energy）的研报分析，以下为三段论总结及跳过（SKIP）决策理由：

**历史回顾：**  
IREN 早期作为一家专注于比特币矿业的公司，凭借其低成本水力发电优势和数据中心运营经验，在上一轮周期中实现了算力的快速扩张。然而，其股价及运营高度依赖比特币价格与全网算力竞争格局，曾在熊市中经历盈利压力与融资挑战。

**当前状态：**  
公司已向“高算力+AI计算”双轮驱动转型，在加拿大、澳大利亚等地推进高功率数据中心建设，并部署了英伟达H100等GPU用于AI推理服务。但其核心比特币挖矿业务仍受减半效应影响，单位产出下滑；AI业务尚处于早期投入期，收入贡献有限，且面临大型科技公司的竞争。

**未来预期：**  
若比特币价格维持高位且AI算力租赁需求持续增长，IREN有望通过低电价优势与存量基础设施实现盈利改善。但风险在于：1）AI业务商业化节奏不及预期；2）比特币价格波动导致现金流承压；3）全球数据中心建设成本与融资压力上升。

**决策：跳过（SKIP）**  
**理由：** IREN当前处于“过渡期”而非“拐点”。其比特币业务受减半压制，未来可见的营收增长主要依赖低确定性AI业务，而后者需大量资本开支且回报周期长。在缺乏明确的盈利催化剂与充分的风险补偿时，当前估值缺乏安全边际，风险收益比不具吸引力，故建议跳过。
