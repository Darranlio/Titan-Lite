## 1. 🔍 公司业务 DNA
::: info Exxon Mobil Corporation
埃克森美孚公司（Exxon Mobil Corporation）主要从事原油与天然气的勘探及生产业务，业务覆盖美国、加拿大及国际市场。公司下设上游、能源产品、化工产品及特种产品四大业务板块。上游板块负责原油与天然气的勘探与生产；能源产品板块提供燃料、芳烃、催化剂及相关技术授权服务；化工产品板块从事烯烃、聚烯烃及中间体的制造与销售；特种产品板块则提供成品润滑油、基础油、蜡类、合成材料、弹性体及树脂等产品。此外，公司还涉及原油、天然气、石油产品、石化产品及其他特种产品的制造、贸易、运输与销售，并积极拓展低碳业务机遇，包括碳捕集与封存、氢能、低碳燃料、Proxxima树脂体系、碳材料、低碳数据中心及锂资源开发。公司同时供应航空燃油，旗下产品以Exxon、Esso及Mobil品牌进行销售。埃克森美孚公司成立于1870年，总部位于得克萨斯州斯普林市。
:::

## 6. 🧠 投研三段论
**三段论总结：埃克森美孚（XOM）**

- **历史回顾**：过去十年，XOM 经历了从传统上游主导向“油气+低碳”双轮驱动的战略转型，但受制于2014-2020年的油价低迷与新冠疫情冲击，其资本纪律与股东回报一度承压，直至2021年后随能源价格反弹与成本削减见效，自由现金流大幅改善。
- **当前状态**：2024-2025年，XOM 处于高油气价格红利与低碳投资扩张的平衡期。上游产量稳中有增（二叠纪盆地与圭亚那为核心），炼化与化工板块受益于北美天然气低成本优势；同时，碳捕集与氢能等新业务虽处于早期阶段，但资本支出占比已提升至15%-20%。资产负债表健康，股息连续增长，回购节奏稳定。
- **未来预期**：中期看，若全球油气供需维持紧平衡（OPEC+减产、美国页岩油增速放缓），XOM 有望保持强劲现金流与股东回报；长期则面临能源转型加速下需求峰值风险。其低碳业务能否成为第二增长曲线，取决于政策支持（如《通胀削减法案》补贴）与技术进步。

**决策观察（WATCH）理由：**
当前建议 **持有并观察**，核心逻辑如下：
1. **估值合理但上行空间有限**：当前 EV/EBITDA 约7倍，处于历史中位，需油价持续高于70美元/桶才能支撑当前股价，而全球经济放缓风险可能压制需求预期。
2. **催化剂与风险并存**：正向催化剂包括圭亚那项目新增产量、低碳业务政策受益；下行风险包括 OPEC+ 增产、美国页岩油潜在资本开支加速、绿色政策退坡。
3. **资本配置平衡**：公司同时提升股息与回购（预计2025年回馈股东超300亿美元），但若低碳转型成本超预期或回报率低于传统业务，可能拖累长期ROCE。

综上，建议维持现有仓位，重点关注2025年一季度财报中关于产量指引、低碳项目IRR及回购计划的细节，以评估是否调整仓位。
