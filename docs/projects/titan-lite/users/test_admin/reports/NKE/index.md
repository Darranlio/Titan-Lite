## 1. 🔍 公司业务 DNA
::: info NIKE, Inc.
耐克公司（NIKE, Inc.）及其子公司主要从事运动及休闲鞋类、服装、装备、配件及相关服务的研发、设计、营销与销售，产品覆盖北美、欧洲、中东、非洲、大中华区、亚太及拉丁美洲市场，目标客群涵盖男性、女性及儿童。公司旗下品牌包括NIKE、Jordan、Jumpman、Converse、Chuck Taylor、All Star、One Star、Star Chevron及Jack Purcell等。此外，公司提供一系列高性能装备及配件，如包袋、袜子、运动球类、眼镜、钟表、数字设备、球棒、手套、护具及其他运动器材，并向其他制造商供应多种塑料制品；同时分销及授权休闲运动鞋、服装及配件，并销售印有授权大学、职业球队及联盟标志的服装。公司还提供消费者服务与体验，包括以运动为主题的活动与推广、健身及运动类应用程序、运动健身与健康内容，以及零售门店内的数字化服务与功能。其销售渠道涵盖鞋店、体育用品店、运动专业店、百货商场、滑板/网球/高尔夫用品店，并通过耐克直营零售店、独立分销商、授权商、销售代表及数字平台向其他批发客户供货。该公司前身为蓝带体育公司（Blue Ribbon Sports, Inc.），于1971年5月更名为耐克公司。耐克公司创立于1964年，总部位于俄勒冈州比弗顿市。

## 6. 🧠 投研三段论
**NKE（耐克）研报三段论总结与决策观察（WATCH）理由**

**一、历史回顾：增长引擎承压，库存周期主导波动**  
过去三年，NKE 在全球运动品牌中保持领先地位，凭借直营（DTC）转型与创新产品（如 Air Jordan、Pegasus 系列）驱动营收增长。但2022-2023财年，受北美消费疲软、大中华区竞争加剧（本土品牌如安踏、李宁崛起）以及过度依赖折扣清库存影响，毛利率持续下滑，营收增速放缓至低个位数，股价经历近40%回撤。

**二、当前状态：转型阵痛期，战略调整初现成效**  
2024财年至今，NKE 处于“降库存、调渠道、强创新”的关键阶段：  
- **财务端**：库存同比降幅超10%，毛利率企稳（环比提升1.2pct），但营收仍受制于批发渠道收缩与促销常态化。  
- **运营端**：新任CEO Elliott Hill 主导“回归体育”战略，加大跑步、女性及儿童品类投入，AI定制平台“Nike Fit”逐步落地。  
- **风险点**：大中华区营收连续两季同比下滑（-6%），地缘与消费分层压力未消；全球运动鞋服需求增速放缓至3%以下。

**三、未来预期：结构性修复可期，但弹性空间有限**  
- **短期（1-2年）**：库存正常化叠加新品渗透（如Air Max Dn、Pegasus Premium），预计营收增速回升至3%-5%，毛利率修复至44%-45%（当前42.8%）。  
- **中期（3-5年）**：DTC占比有望提升至45%（当前40%），数字化收入贡献突破30%；但需警惕竞争对手（Adidas、On Running）在高端跑鞋与生活方式品类的持续蚕食。  
- **估值**：当前PE约26x，略低于5年均值（28x），若利润率未达预期，存在进一步下修可能。

**四、决策观察（WATCH）理由**  

持有 **WATCH（观望）** 评级，理由如下：  
1. **估值合理但催化因素不足**：PE处于历史中位，但营收增长拐点尚未确认，需等待2-3个财报季度验证利润率修复趋势。  
2. **结构性风险待化解**：大中华区衰退与全球消费降级是核心变量；若新品反响不及预期，或本土品牌进一步分流，股价存在10%-15%下行风险。  
3. **等待确定性信号**：关注下季度库存周转天数、DTC毛利率改善以及大中华区营收止跌。在以上任一信号明确前，维持观望，避免追高或过早左侧布局。  

**综上**：NKE 正处于“库存出清→利润率修复”的过渡期，短期缺乏强催化剂，建议保持观望，待基本面拐点信号明朗后再行决策。
