## 1. 🔍 公司业务 DNA
::: info AT&T Inc.
AT&T Inc.（美国电话电报公司）在全球范围内提供电信及技术服务。公司业务分为两大板块：通信业务和拉丁美洲业务。通信板块提供无线语音及数据通信服务；并通过自有门店、代理商及第三方零售渠道销售手机、无线数据卡、无线计算设备、携带包/保护壳及无线充电器等产品。此外，该板块还提供AT&T专用互联网、光纤以太网及宽带、固定无线接入、托管及管理专业服务；以及面向跨国公司、中小企业、政府及批发客户的铜缆语音及数据服务、虚拟专用网络（VPN）、批发、外包、IP服务及客户终端设备。同时，该板块为住宅用户提供宽带服务（包括光纤连接）、传统电话语音通信服务及其他VoIP服务与设备。通信板块以AT&T、AT&T Business、Cricket、AT&T PREPAID、AT&T Fiber及AT&T Internet Air等品牌推广其通信服务及产品。拉丁美洲板块在墨西哥以AT&T及Unefon品牌提供后付费及预付费无线服务，并通过自有门店、代理商及第三方零售渠道销售智能手机。该公司前身为SBC Communications Inc.，于2005年更名为AT&T Inc.。AT&T Inc.成立于1983年，总部位于德克萨斯州达拉斯。
