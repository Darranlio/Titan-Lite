## 1. 🔍 公司业务 DNA
::: info Celsius Holdings, Inc.
Celsius Holdings, Inc. 在美国、北美、欧洲、亚太及国际市场从事功能性能量饮料的研发、加工、制造、营销、销售及分销业务。公司旗下产品包括：添加氨基酸的功能性能量饮料 CELSIUS ESSENTIALS；零糖电解质水粉系列 CELSIUS Hydration（提供多种水果风味）；以及以 CELSIUS、Alani Nu 和 Rockstar 品牌销售的即饮能量饮料、便携粉末及水棒、营养健康产品。其分销渠道涵盖直送门店配送、独立经销商、超市、便利店、药店、营养品店、食品服务商、大众零售商，以及天然食品店、健身中心、大型零售卖场、维生素专营店、会员制仓储店、健身房和电商平台。该公司前身为 Vector Ventures, Inc.，于 2007 年 1 月更名为 Celsius Holdings, Inc.，成立于 2004 年，总部位于佛罗里达州博卡拉顿。
:::

## 6. 🧠 投研三段论
基于对CELH（Celsius Holdings）的财务数据、行业竞争格局及市场情绪的综合分析，以下为三段论研报总结及决策建议：

**一、历史回顾：超高速增长后的估值泡沫消退**  
CELH在2020-2022年间受益于功能性饮料赛道爆发及百事战略入股，营收复合增长率超100%，股价在2023年达到峰值。但2024年起，公司面临库存积压、北美便利店渠道增速放缓（核心增速从+60%骤降至+15%），叠加营销费用（赞助F1、电竞等）回报率低于预期，股价自高点回撤超70%，估值从60倍PS压缩至当前4倍PS，市场已对“高增长神话”进行重新定价。

**二、当前状态：盈利能力承压与竞争加剧**  
2024年Q3财报显示，收入同比增速仅+12%（远低于历史均值），毛利率受铝罐成本及物流效率拖累下滑至48%（前值52%）。百事分销协同效应未能完全释放，且Monster Beverage、红牛及自有品牌（如星巴克罐装咖啡）在RTD领域持续抢占份额。存货周转天数升至85天（同比+20%），暗示渠道动销弱于预期。当前静态PE约35倍，对应当前低增速仍显偏高。

**三、未来预期：非线性复苏概率较低，需等待结构性验证**  
管理层2025年指引营收增速10-15%，但需关注两大节点：  
1) **国际扩张转向**：欧洲/非洲分销网络（通过百事渠道）若实现盈亏平衡（当前仍亏损），可能提升毛利率至52%以上；  
2) **新品（Celsius VIBE）渗透率**： 若占营收比突破15%且不蚕食经典款，才可视为第二曲线。  
中性情景下，2025年EPS或仅0.65美元（同比+18%），对应远期PE仍超30倍，需至少连续两个季度超预期交付方能重获溢价。  

**决策建议：SKIP（跳过）**  
**理由**：当前估值虽处历史低位，但基本面未现触底信号（存货高企、竞争加剧、百事协同延迟）。市场需看到明确的**需求再加速**（如单店销量回升）或**成本结构改善**（毛利率回升至52%+）证据，否则股价将挣扎于区间震荡。投资者宜等待Q1 2025财报中渠道补库趋势及新品复购率数据，再行评估入场时机。
