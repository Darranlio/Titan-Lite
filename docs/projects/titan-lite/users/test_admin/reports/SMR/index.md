## 6. 🧠 投研三段论
**SMR（小型模块化反应堆）研报三段论总结与决策建议**

**历史回顾**  
SMR概念自21世纪初兴起，旨在突破传统大型核电站的高资本门槛与长建设周期。早期研发聚焦于安全性与模块化设计验证，但受制于技术成熟度不足、监管路径缺失及经济性争议，多数项目长期停留在纸面或示范阶段，商业化进程缓慢。

**当前状态**  
全球已有多个SMR设计进入工程验证或取证阶段（如NuScale、Rolls-Royce等），部分项目获政府专项补贴与选址许可。然而，供应链尚未规模化、首堆成本超支风险突出，且核废料处理与公众接受度仍是制约因素。市场呈现“政策热、落地冷”的阶段性特征。

**未来预期**  
若技术迭代与系列化生产能降低度电成本30%-50%，SMR有望在2030-2040年填补基荷与间歇性可再生能源之间的空白，尤其适用于偏远地区、工业供热及制氢场景。但需警惕监管碎片化、铀燃料供应瓶颈及与天然气调峰竞争的替代风险。

**决策：跳过（SKIP）**  
**理由**：当前SMR尚未突破经济性与规模化的“死亡之谷”，首堆平准化度电成本（LCOE）远超传统核电与风光+储能组合。技术路线仍存分化，政策依赖度极高，短期投资回报确定性低。建议持续跟踪首堆商业化运营数据与碳定价机制进展，在技术收敛与成本曲线明确前暂不配置敞口。
