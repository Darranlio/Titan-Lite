## 1. 🔍 公司业务 DNA
::: info Amazon.com, Inc.
亚马逊公司（Amazon.com, Inc.）主要从事北美及国际市场的线上与实体零售业务，涵盖消费品销售、广告服务及订阅服务。公司下设三大业务板块：北美、国际及亚马逊网络服务（AWS）。其业务范围还包括电子设备制造与销售（如Kindle、Fire平板、Fire TV、Echo、Ring、Blink及Eero），以及媒体内容的开发与制作。此外，公司为卖家提供在其平台销售产品的服务，并为作者、独立出版商、音乐人、电影制作人、Twitch主播、技能与应用程序开发者等群体提供内容发布与销售支持。在技术领域，公司提供计算、存储、人工智能、数据库、分析、机器学习等服务，并通过赞助广告、展示广告及视频广告等模式提供广告服务。同时，公司推出会员计划Amazon Prime。其平台销售的商品包括自营采购的转售商品及第三方卖家提供的产品。服务对象涵盖消费者、卖家、开发者、企业、内容创作者、广告主及员工。该公司成立于1994年，总部位于华盛顿州西雅图。

## 6. 🧠 投研三段论
**AMZN 研报三段论总结**

**历史回顾**  
亚马逊长期受益于电商渗透率提升与AWS云服务的高增长，从零售巨头转型为全球云计算与数字化基础设施龙头。过去十年，营收与利润持续扩张，但期间经历疫情红利消退、供应链成本高企及增长放缓后的估值回调。

**当前状态**  
亚马逊处于“降本增效”与“新增长引擎”并行阶段。核心电商业务增速趋于稳定，AWS受企业IT支出谨慎影响短期承压，但仍是利润核心。广告与第三方卖家服务贡献增量，同时AI基础设施投入（如自研芯片、大模型）成为新竞争力。当前估值处于历史中位水平，市场等待盈利改善与催化信号。

**未来预期**  
中期看好AWS需求回暖（伴随AI部署加速）与零售利润率持续改善，长期增长点在于生成式AI商业化、医疗及物流生态扩张。但需警惕反垄断、监管及宏观消费疲软风险。预计未来12-18个月营收增速回升至10%-12%，利润率环比改善，目标价基于DCF模型中枢看涨约15%。

**决策建议：WATCH（观察）**  
理由：  
1. **估值合理性存疑**：当前PE约45倍，虽低于历史高位，但尚未反映AWS增速放缓的潜在时间延长。  
2. **催化剂待验证**：AI驱动的云服务增量需体现在2024下半年财报中，盈利拐点尚未完全确认。  
3. **宏观逆风未消**：高利率环境持续压制大型企业IT预算，零售消费韧性面临不确定性。  
建议等待AWS订单加速信号或Q2财报超预期后，再考虑增持；若股价回调至120美元以下（对应PE 35倍），则转向BUY。
