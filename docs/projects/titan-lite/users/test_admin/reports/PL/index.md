# 🚀 PL 投研价值看板

## 1. 🔍 公司业务 DNA
::: info Planet Labs PBC
Planet Labs PBC（行星实验室公益公司）主要从事卫星星座的设计、建造与发射，旨在通过在线平台向美国及国际客户提供高频次地理空间数据。该公司推出的SuperDove卫星可构建地球全天候扫描系统，目标是以最高3.5米地面采样距离（GSD）分辨率实现每日全球成像，并将行星监测与公共卫星数据项目提供的其他科学级辐射测量数据相结合；其SkySat与Pelican卫星则通过应用程序编程接口（API）驱动，每日多次捕获指定地点影像，经处理后GSD分辨率可达50厘米。此外，公司还提供高光谱成像卫星Tanager，可获取可见光至短波红外波段的全光谱影像，并依托地球观测平台，使客户与合作伙伴能够通过发现影像任务能力、相关数据层、提取有效信息，并借助API及基于浏览器的应用，通过定制化解决方案或GIS工作流访问、分析其专有数据目录并据此采取行动。在卫星服务方面，公司业务涵盖客户自有卫星的设计制造、任务系统工程、发射采购、地面站基础设施、卫星运维，以及公司或客户自有卫星的专属影像任务能力。其服务对象涵盖农业、测绘、能源、林业、金融、保险企业及政府机构。Planet Labs PBC成立于2010年，总部位于加利福尼亚州旧金山。
:::

## 6. 🧠 投研三段论
**历史回顾**  
PL（Planet Labs）自2010年成立以来，通过部署大规模低轨遥感卫星星座，率先实现了“每日全球覆盖”的影像采集能力。其商业模式从政府与农业客户起步，逐步扩展至环境监测、国防情报等领域，积累了高频、全色遥感数据资产。但受限于早期星座技术迭代与商业化落地速度，收入增长波动较大，且持续面临高资本开支与现金流压力。

**当前状态**  
截至2025年初，PL已具备超200颗在轨卫星，实现每日全球影像高频更新，并在AI分析、数据API订阅等增值服务上取得进展。客户结构趋于多元化，国防与商业收入占比提升。然而，公司仍处于亏损状态，自由现金流尚未转正，且面临来自Maxar、BlackSky等对手在分辨率与精准任务响应上的竞争。近期财报显示营收增速放缓，市场对其盈利时间表预期存疑。

**未来预期**  
若PL能进一步降低卫星制造成本、拓宽高附加值下游应用（如碳监测、实时灾害响应），并依托政府长期合同实现现金流拐点，则有望在2026-2027年进入盈利阶段。但若竞争加剧导致定价压力，或用户切换至AI+合成数据方案，其差异化优势可能被侵蚀。总体看，增长确定性低于预期，估值已部分透支利好。

**决策理由（SKIP）**  
当前PL基本面处于“规模化验证未果、盈利路径模糊”的时点，下行风险（竞争、现金流、商业落地节奏）大于上行催化。建议跳过（SKIP），等待更清晰的季度盈利指引或技术/合约突破后再评估。
