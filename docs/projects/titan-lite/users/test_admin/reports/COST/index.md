## 1. 🔍 公司业务 DNA
::: info Costco Wholesale Corporation
好市多批发公司（Costco Wholesale Corporation）及其子公司在美国、波多黎各、加拿大、墨西哥、日本、英国、韩国、澳大利亚、中国台湾、中国大陆、西班牙、法国、冰岛、新西兰及瑞典经营会员制仓储超市。公司销售商品涵盖：日用杂货、干货、糖果、冷藏食品、冷冻食品、熟食、酒类及烟草；非食品类商品包括家电、小型电子产品、健康美容用品、五金工具、草坪园艺用品、运动器材、轮胎、玩具及季节性商品、汽车用品、邮票、票务、服装、家具、家纺、厨具、定制服务终端及珠宝；生鲜食品包括肉类、农产品、熟食及烘焙产品。此外，公司还经营仓储附属业务，包括加油站、药房、眼镜店、美食广场、助听器中心及轮胎安装中心。同时，公司亦开展电子商务、商务中心、旅游及其他业务。该公司前身为Costco Companies, Inc.，于1999年8月更名为现名。好市多批发公司创立于1976年，总部位于华盛顿州伊瑟阔市。

## 6. 🧠 投研三段论
**历史回顾**  
Costco（COST）长期践行“会员费+低毛利+高周转”模式，依托全球供应链效率与仓储式零售壁垒，实现营收与利润的稳定增长。过去十年，同店销售复合增速维持在5%-7%，会员续费率超90%，忠实用户基础构筑了高护城河。

**当前状态**  
通胀趋缓、消费降级背景下，COST凭借价格优势与自有品牌Kirkland吸引力，客流持续提升。当前市占率稳中有升，单季可比销售增速仍保持在4%-6%区间。但短期面临运输成本波动与电商渗透加速的潜在压力，估值处于历史偏高位置。

**未来预期**  
全球扩张（尤其亚洲市场）与数字化能力提升将为收入增长提供新动能。预计未来三年营收复合增速约6%-8%，经营利润率在会员费提价及运营优化下小幅改善。若宏观消费保持韧性，盈利可持续性较强。

**决策观察（WATCH）理由**  
当前估值隐含较高增长预期，需持续监控：  
1. **同店销售趋势**：能否在高基数下维持正增长；  
2. **会员增长与续费率**：尤其海外市场渗透节奏；  
3. **库存与成本管理**：应对通胀与租金上升的能力。  
基础面稳健但短期上行空间受限，建议维持观望，等待估值回归合理区间后介入。
