## 1. 🔍 公司业务 DNA
::: info POET Technologies Inc.
POET Technologies Inc. 及其子公司主要从事半导体产品与服务的设计、开发、制造及销售业务，服务于美国、加拿大、南北美洲其他地区、欧洲、马来西亚、新加坡、中国及亚洲其他地区的商业应用领域。公司基于POET光学中介层（POET Optical Interposer）平台提供光子集成封装解决方案，该平台采用先进的晶圆级半导体制造技术，可将电子与光子器件集成至单一芯片。其产品涵盖光子集成电路、光学引擎、光收发模块及光源产品。公司业务覆盖数据中心人工智能、光源及电信市场；5G互连市场（如PON与GPON），以及面向机器间通信的边缘计算领域；同时服务于传感市场，包括激光雷达（LiDAR）、医疗设备用光学相干断层扫描（OCT）及虚拟现实系统。公司与Lumilens Inc.建立战略合作，共同开发面向人工智能光网络的晶圆级光子集成技术。该公司前身为Opel Technologies Inc.，于2013年6月更名为POET Technologies Inc.，总部位于加拿大多伦多。
:::

## 6. 🧠 投研三段论
**三段论总结：POET（光互连与封装技术）研报**

**1. 历史回顾**  
POET 曾作为无晶圆厂半导体设计公司，长期专注基于“光引擎”（Optical Engine）的硅光子技术研发，但受限于工艺成熟度与客户验证周期，早期营收主要依赖少量定制化产品，股价随技术迭代预期波动，未实现规模化商业落地。

**2. 当前状态**  
公司已与多家数据中心及 AI 算力客户达成联合开发协议，其 100G/400G 光引擎模块进入量产验证阶段，基于 3D 先进封装的技术路径在功耗与带宽密度上具备差异化优势。但当前仍处于亏损状态，现金流依赖融资，且面临 Intel、Cisco 等巨头的竞争挤压。

**3. 未来预期**  
若光引擎在 800G/1.6T 时代切入 AI 集群内部互连场景，2025-2026 年有望实现千万美元级营收；但需警惕产能爬坡不及预期、客户切换成本高及行业库存周期波动等风险。长期增长取决于能否在硅光子全集成方案中建立生态壁垒。

---

**决策：跳过 (SKIP)**  
**理由**：  
- **不确定性集中**：当前估值已部分透支未来 2-3 年的预期，然技术量产节奏与客户订单均存在显著变数，缺乏确定性股价催化剂。  
- **流动性风险**：市值较小且无稳定营收支撑，一旦行业资金转向或产业链进度迟滞，将面临较大回调压力。  
- **性价比不足**：同等云计算/光互连赛道中，存在更成熟、现金流更优的替代标的（如 Coherent、Lumentum），POET 的风险补偿有限。  
- **等待信号**：建议在 800G 光引擎进入规模出货确认（如季度营收突破 500 万美元或新增头部客户）后再行评估。
