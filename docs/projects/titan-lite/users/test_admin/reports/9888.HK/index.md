## 1. 🔍 公司业务 DNA
::: info Baidu, Inc.
百度股份有限公司（Baidu, Inc.）于中华人民共和国境内提供互联网内容、增值电信服务、互联网地图及在线音视频服务。公司业务分为两大板块：百度核心业务（Baidu General Business）与爱奇艺（iQIYI）。百度核心业务板块涵盖移动生态、AI云及智能驾驶领域的产品与服务。该板块运营百度App，使用户可通过移动设备获取搜索、信息流、内容及其他服务；同时运营好看视频（Haokan），提供用户生成及专业制作的多样化短视频内容。此外，该板块还提供一系列知识信息产品，包括：百度百科（Baidu Wiki），以专栏及视频形式呈现非物质文化遗产百科、数字博物馆及历史记录等内容；百度知道（Baidu Knows），一个用户（含个人、专业人士及企业）可相互提问的在线社区；百度经验（Baidu Experience），用户分享日常知识与经验的在线平台；文心一言（ERNIE Bot），一款面向PC及移动端的新一代AI原生多轮对话助手；以及百度贴吧（Baidu Post），支持用户发布文字、图片、音频及视频内容，并可通过回复原创内容形成有价值的讨论群组。该板块亦提供直播服务，包括传统直播及AI驱动的数字人直播。此外，公司还提供中文智能助手小度助手（DuerOS）、自动驾驶出行服务平台萝卜快跑（Apollo Go）、在线营销服务、具备语音功能的出行服务应用百度地图（Baidu Maps）及AI芯片。爱奇艺板块专注于专业制作内容的制作与发行，提供在线娱乐视频服务，涵盖在线视频、体验服务、网络游戏、动漫等。公司成立于2000年，总部位于中华人民共和国北京。

## 6. 🧠 投研三段论
关于 **9888.HK（百度集团-SW）** 的三段论总结及决策建议如下：

**一、历史回顾**  
百度作为中国AI与搜索领域的先驱，近年经历了核心广告业务增速放缓（受宏观经济及短视频冲击）、移动生态承压的阵痛。但公司前瞻性布局AI（如文心一言、自动驾驶Apollo），长期研发投入形成技术壁垒，股价在2021年触顶后持续回调，估值消化至历史低位。

**二、当前状态**  
基本面呈现“传统业务筑底、AI业务加速”格局：  
- **广告**：受益于AI生成内容（AIGC）赋能搜索效率，收入企稳，但增量有限；  
- **云服务**：AI商业化主要载体（大模型调用量高速增长），但短期价格战影响盈利；  
- **自动驾驶**：萝卜快跑初步验证商业模式，但规模化盈利仍需时日。  
**估值**：PE（TTM）约12倍，处于近5年低位，但市场对AI变现的不确定性持观望态度。

**三、未来预期**  
**核心驱动力**：  
1. **文心大模型**：若企业端API调用量及B端解决方案收入超预期（如智能云渗透率提升），可开启二次增长曲线；  
2. **智能驾驶**：武汉等城市运营数据若证明单位经济模型跑通，有望触发估值重估；  
3. **降本增效**：非核心业务收缩（如YY直播出售）或带来利润弹性。  
**主要风险**：AI商业化低于预期、宏观广告需求疲软、竞争加剧（如字节、阿里云）。

**决策建议：跳过 (SKIP)**  
**理由**：  
1. **短期催化不足**：AI收入尚未形成规模性突破，且行业价格战压制盈利预期；  
2. **估值合理性**：当前估值已部分反映悲观预期，但缺乏明确上行催化剂（如业绩超预期或政策利好）；  
3. **机会成本**：相较其他高弹性科技标的（如AI芯片、SaaS），百度股价波动与收益风险比暂不突出。建议等待AI云业务季度财报验证放量趋势或自动驾驶政策明确突破后再行入场。
