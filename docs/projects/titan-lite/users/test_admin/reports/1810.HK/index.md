## 6. 🧠 投研三段论
针对 **1810.HK（小米集团）** 的三段论总结及决策观察（WATCH）理由如下：

**历史回顾 | 从“性价比”突围到高端化阵痛**  
小米自2018年上市以来，经历了从智能手机“性价比”标杆到IoT生态扩张的快速增长期。2021年市值一度接近万亿港元，但随后受全球芯片短缺、国内市场竞争加剧及华为回归冲击，股价回撤超60%。2023年，公司明确“规模与利润并重”策略，削减非核心业务开支，并通过“人车家全生态”战略（含SU7汽车发布）重塑增长叙事。

**当前状态 | 汽车业务破局，手机盈利改善**  
2024年Q1财报显示：手机业务毛利率提升至14.8%（高端机型占比突破20%），IoT业务受益于海外扩张保持双位数增长。SU7电动车订单超8万辆（截至2024年5月），交付节奏超预期，带动市场对其第二增长曲线（智能汽车）的估值修复。但汽车业务仍处于亏损爬坡期（单车毛利为负），且面临特斯拉、比亚迪等头部车企的价格战压力。

**未来预期 | 汽车放量与生态协同是关键变量**  
小米智能汽车业务将成为核心催化剂：若2025年交付量突破30万辆且毛利率转正，可能推动市值突破5000亿港元。但需警惕：1）汽车行业产能过剩导致价格战持续；2）汽车与手机、家电生态协同的兑现度（如OS统一性）；3）手机高端化能否在华为、苹果挤压下持续突破。此外，印度市场政治风险及关税壁垒仍存。

**决策观察（WATCH）理由**  
**建议维持“观察”**：  
- **积极因素**：SU7订单转化为收入、汽车毛利率拐点、手机高端化及AIoT海外渗透率提升。  
- **风险警示**：汽车产能瓶颈、行业价格战吞噬利润、手机份额受华为进一步侵蚀。  
- **关键节点**：2024年下半年汽车月度交付量能否稳超2万辆、Q3手机出货量及ASP变化。  

**结论**：当前估值（PE 32x）已部分反映汽车预期，但尚未验证盈利能力。需等待汽车业务毛利率转正信号及手机+AIoT协同效应数据。建议在SU7季度毛利率突破5%前保持谨慎，暂不介入。
