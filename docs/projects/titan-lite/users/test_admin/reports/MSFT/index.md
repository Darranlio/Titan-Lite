## 6. 🧠 投研三段论
**历史回顾**  
微软（MSFT）凭借Azure云服务、Office 365订阅及游戏业务的持续增长，过去五年营收及利润保持双位数扩张。受AI战略初期投入影响，估值中枢上移，但盈利韧性支撑股价表现。

**当前状态**  
公司处于AI商业化加速阶段，Azure AI服务收入同比增速超100%，智能云收入占比突破45%；资本开支因算力基建短期承压，但毛利率维持68%高位。Windows及办公软件现金流稳定，为AI投资提供安全垫。

**未来预期**  
预计FY2025-2027年AI生态将贡献新增收入超300亿美元，并通过Copilot订阅、企业级模型调优服务提升用户黏性。智能云增速或边际放缓至20%左右，但整体营收仍有望维持中双位数增长，利润结构向高margin的AI及云端倾斜。

**决策观察（WATCH）理由**  
当前观察逻辑基于两点：一是**估值消化期**，当前TTM PE约33倍，对应当前AI投入回报尚未完全反映，需等待毛利率拐点；二是**风险敞口**，需持续监测资本开支强度对自由现金流的压制（当前FCF yield约2.6%）。若未来两季云服务增速超预期或资本开支效率提升，将构成上调至“买入”的触发信号。
