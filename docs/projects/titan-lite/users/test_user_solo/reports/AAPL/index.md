## 1. 🔍 公司业务 DNA
::: info Apple Inc.
苹果公司（Apple Inc.）在全球范围内设计、制造并销售智能手机、个人电脑、平板电脑、可穿戴设备及配件。其产品线包括：iPhone系列智能手机、Mac系列个人电脑、iPad系列多功能平板电脑，以及可穿戴设备、家居与配件（涵盖AirPods、Apple Vision Pro、Apple TV、Apple Watch、Beats产品、HomePod，以及苹果品牌与第三方配件）。此外，公司提供AppleCare支持服务与云服务，并运营包括App Store在内的多个平台，使用户能够发现并下载应用程序及数字内容（如书籍、音乐、视频、游戏、播客等），同时提供广告服务（包括第三方授权安排及自有广告平台）。公司还推出多种订阅制服务，例如：游戏订阅服务Apple Arcade、个性化健身服务Apple Fitness+、提供精选收听体验及点播电台的Apple Music、新闻与杂志订阅服务Apple News+、提供独家原创内容及体育赛事直播的Apple TV、联名信用卡Apple Card、无现金支付服务Apple Pay，并开展知识产权授权业务。其客户涵盖消费者、中小企业，以及教育、企业和政府市场。公司通过App Store为其产品分发第三方应用程序，并通过零售店、在线商店、直销团队，以及第三方移动网络运营商与经销商销售产品。该公司前身为Apple Computer, Inc.，于2007年1月更名为Apple Inc.。苹果公司成立于1976年，总部位于加利福尼亚州库比蒂诺。
:::

## 6. 🧠 投研三段论
**历史回顾**  
苹果（AAPL）凭借iPhone生态与高粘性服务（App Store、iCloud）持续驱动营收增长，过去五年年均复合增长率约8%，利润端受益于高端化定价与供应链效率提升，市值屡创新高；但2021年后受全球消费电子周期放缓、监管压力（反垄断、支付合规）影响，增速明显放缓，估值波动加剧。

**当前状态**  
核心产品线进入成熟期，iPhone 16系列备货量平稳，服务收入同比+14%支撑利润率（毛利率维持46%）；AI功能（Apple Intelligence）逐步接入系统，但短期贡献有限。宏观层面，美国利率转向预期提升高估值科技股吸引力，叠加苹果大规模回购（季度回购约200亿美元），EPS稳定增长。风险在于中美贸易摩擦升级及欧盟数字市场法案合规成本上升。

**未来预期**  
长期增长依赖AI终端渗透（iPhone换机周期缩短）、硬件订阅模式拓展及新兴市场（印度、东南亚）份额提升；预计FY2025-2027年营收增速回升至5%-7%，服务占比超30%。若Vision Pro二代定价下探至消费级，或贡献增量估值弹性。

**决策：Buy**  
理由：当前PE约29倍（万得一致预期），位于近五年中位偏低；服务业务现金流稳健提供安全垫，AI叙事催化估值修复；叠加持续回购与分红（股东回报率超4%），下行风险有限。建议现价区间建仓，目标价270美元（对应FY2025 PE 33x）。
