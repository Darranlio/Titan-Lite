## 1. 🔍 公司业务 DNA
::: info Apple Inc.
苹果公司（Apple Inc.）在全球范围内设计、制造并销售智能手机、个人电脑、平板电脑、可穿戴设备及配件。其产品线包括：iPhone系列智能手机、Mac系列个人电脑、iPad系列多功能平板电脑，以及可穿戴设备、家居与配件类产品（涵盖AirPods、Apple Vision Pro、Apple TV、Apple Watch、Beats产品、HomePod，以及苹果品牌与第三方配件）。此外，公司提供AppleCare支持服务与云服务，并运营包括App Store在内的多个平台，使用户能够发现并下载应用程序及数字内容（如书籍、音乐、视频、游戏、播客等），同时提供广告服务（包括第三方授权安排及自有广告平台）。公司还推出多种订阅制服务，例如：游戏订阅服务Apple Arcade、个性化健身服务Apple Fitness+、提供精选收听体验及点播电台的Apple Music、新闻与杂志订阅服务Apple News+、独家原创内容及体育赛事直播的Apple TV、联名信用卡Apple Card、无现金支付服务Apple Pay，并开展知识产权授权业务。其客户涵盖消费者、中小企业，以及教育、企业和政府市场。公司通过App Store为其产品分发第三方应用程序，并通过零售店、在线商店、直销团队，以及第三方蜂窝网络运营商与经销商销售产品。该公司前身为Apple Computer, Inc.，于2007年1月更名为Apple Inc.。苹果公司成立于1976年，总部位于加利福尼亚州库比蒂诺。

## 6. 🧠 投研三段论
**历史回顾**：AAPL 在过去十年凭借 iPhone 生态的强劲收入韧性、服务业务的高速增长及持续的股票回购，实现了超额回报。但近两年受全球智能手机需求饱和、供应链转移成本上升及监管压力（如 App Store 反垄断诉讼）影响，营收增速显著放缓，且毛利率开始承压。

**当前状态**：公司仍维持高利润率（约45%）与强大的自由现金流，但核心硬件销量已连续多个季度同比持平或微降；服务业务虽保持双位数增长，但估值溢价已充分反映这一预期。此外，Vision Pro等新品类尚未形成规模贡献，且AI部署进展慢于同业，导致市场对其增长动力产生疑虑。

**未来预期**：预计未来12-18个月，AAPL将面临美元走强压制海外收入、消费电子换机周期延长、以及AI设备渗透率提升缓慢等结构性挑战。即使叠加潜在的Apple Intelligence催化，其整体营收增速大概率仍低于科技大盘均值，EPS增长将更多依赖回购而非盈利内生扩张。

**决策：Underweight（低配）理由**：在行业增量空间有限、新产品贡献不明朗、且当前约30倍市盈率偏离历史中枢（约25倍）的背景下，AAPL的估值保护不足。相比同类高成长科技股，其风险调整后回报偏低。建议在组合中对AAPL进行低配，降低对估值收缩与基本面边际走弱的风险暴露。
