## 1. 市场洞察与核心痛点 (Market Insights)

### 1.1 目标用户画像
- **中产阶级全球投资者**：具备美股、港股配置需求，但缺乏专业投研能力。
- **金融小白/进阶者**：看不懂枯燥财报，需要有人将复杂数据转化为白话结论。
- **高净值职场人士**：有投资意愿，但无暇每日盯盘，需要高效的决策指令。

### 1.2 核心痛点 (Pain Points)
- **信息过载**：数据太多（Yahoo/Bloomberg），但有效的“结论”太少。
- **认知鸿沟**：专业术语堆砌，导致小白用户产生畏难情绪，决策全靠跟风。
- **市场孤岛**：美股波动对 A 股的影响缺乏直观、自动化的映射逻辑。

---

## 2. 产品差异化护城河 (Differentiation)

### 2.1 跨市场映射 (Cross-Market Mapping)
不同于单纯的海外 AI 工具，Titan-Lite 专注于**全球联动**。能够自动推演美股科技巨头（如 NVDA/TSLA）的波动如何传导至 A 股及港股产业链，提供独家“美股映射”视角。

### 2.2 多 Agent 认知博弈 (Agentic Debate)
系统并非单模型输出，而是模拟真实对冲基金架构。通过**分析师、风险官、交易员**三个 Agent 席位的后台博弈，产出经过多维度验证的深度研报，决策可信度远高于常规 AI。

### 2.3 交互式百科与投研教育 (Interactive Education)
引入**“论文级锚点跳转”词典系统**。在产出高质量研报的同时，通过白话解释帮助小白用户在实战中学习金融常识，实现“工具+教育”的双重粘性。

### 2.4 智力引擎化 (Skill-Centric)
逻辑与代码完全解耦。用户可以根据需求更换“大脑”（Skill），如“宏观择时脑”、“巴菲特价值脑”等，支持高度定制化的投研逻辑。

---

## 3. 商业化变现路径 (Monetization)

### 3.1 SaaS 订阅制 (Subscription)
- **基础版 (Standard)**：提供全市场自动化扫描、每日宏观全景看板、术语百科。
- **专业版 (Professional)**：解锁 1-on-1 深度深研 Agent、实时预挂单提醒、定制化 Skill 导入。

### 3.2 智力商店 (Skill Store)
建立 **Skill 生态**。开发者或专业分析师可以产出并售卖其独有的投研逻辑（Skill 模板），平台抽取佣金。

### 3.3 私域高净值投顾助手 (Private Advisory)
对接企业微信/微信，为高净值用户提供“早间全景驾驶舱”推送及资产风险实时预警。

---

## 4. 演进路线图 (Roadmap)

### 第一阶段：工业化升级 (Infrastructure)
- **中继架构升级**：部署香港 MCP 中继，消除本地代理依赖，实现 SaaS 化访问。
- **UI/UX 驾驶舱化**：从 Markdown 静态展示转向实时、动态的数据驱动看板。

### 第二阶段：内容侧验证 (Market Validation)
- **自媒体流量测试**：利用系统产出的高质量视觉研报在小红书/知乎进行内容分发，验证用户反馈。
- **闭测邀请**：邀请首批 50 位小白用户进行免费测试，收集反馈并打磨百科系统。

### 第三阶段：合规与商业化 (Commercialization)
- **投研辅助工具定位**：明确产品作为“投研数据处理工具”的合规边界。
- **商业 API 切换**：将 FMP/Yahoo 等 API 切换为具备商业授权的版本。

---

## 5. 核心挑战与应对 (Risks)
1. **合规性**：坚持“投研辅助”定位，不直接提供代客理财服务。
2. **数据成本**：通过 MCP 缓存机制和按需抓取策略降低 API 调用频次。
3. **算力成本**：优化 Agent 提示词（Prompt），在轻量化模型与深度思考模型间建立路由平衡。
