# 📖 Titan-Lite 使用手册

## 1. 核心流程：如何生成一份深度研报？

### 方法 A：通过 Web 主页（推荐）
1. 访问 `http://localhost:8080/projects/titan-lite/`。
2. 在“控制面板”中输入股票代码（如 `AAPL`）。
3. 点击 **[开始深度研判]**。
4. 观察控制台输出，等待约 5-10 分钟。
5. 刷新“研报档案”页面查看结果。

### 方法 B：通过 API 调用
发送 POST 请求：
```bash
curl -X POST http://localhost:8000/analyze/NVDA
```

## 2. 如何阅读“个股档案馆”？
档案馆（Reports Archive）不仅有当天的报告，还有一只股票的“成长史”：
- **Dashboard (总览页)**：先看这里的“三段论总结”，快速了解 AI 对该股的长中短期态度。
- **历史演变表**：对比最近几次的 PE 和事实核查分，看公司基本面是否在恶化。
- **深度研报**：点击具体的日期，进入学习模式。

## 3. 💡 学习投资小贴士
在阅读 AI 生成的中文研报时，注意标注了 **【💡 投资课堂】** 的部分。这些是系统根据 DeepSeek 的专业金融理解为你准备的知识点：
- **多空辩论**：不要只看结论，要看 Bear Agent 提出的反面观点，这能帮你建立批判性思维。
- **量价验证**：如果 Verification 结果是“警告”，即使 AI 看多，也要警惕资金流的真实意图。

## 4. 常见问题 (FAQ)
- **Q: 为什么研判时间这么长？**
  - A: 系统正在调用多个专家 Agent 进行数据挖掘和辩论，这是一个深度思考过程，而非简单的 API 查询。
- **Q: 数据显示 Delisted？**
  - A: 系统会自动封顶到当前日期，如果仍然显示无数据，请检查网络是否能访问 Yahoo Finance。
