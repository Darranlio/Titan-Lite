# 🏗️ Titan-Alpha：Titan-Lite 全链路架构升级施工计划 (2026 Q2)

## 🎯 总体目标
将 Titan-Lite 升级为 **“数据解耦、逻辑增强、产出多元”** 的专业级投研终端。
1.  **Reader (解耦化)**：引入 **MCP (Model Context Protocol)**，实现数据源的即插即用。
2.  **Orchestrator (混合化)**：融合“专业分包”与“多方辩论”，先预处理数据（分包调研），再深度博弈（多空辩论）。
3.  **Writer (动作化)**：产出合规推文、结构化交易指令及 Excel 估值模型。

---

## 🛠️ 施工路线图与验收节点

### 第一阶段：Reader 升级 —— 引入 MCP 协议
**目标**：将硬编码的数据抓取逻辑（yfinance, Finnhub）迁移至 MCP 服务器模式。
*   **动作 1**：构建 `mcp_client.py` 核心，支持调用标准 MCP 服务器。
*   **动作 2**：重构 `data_provider.py`，将其改写为 MCP 客户端接口，解耦具体抓取逻辑。
*   **动作 3**：封装首个“金融 MCP 服务端”，集成港美股历史行情与分析师预测数据。

> **🏁 验收节点 1：数据解耦验证**
> *   **验收方式**：运行 `python tests/test_mcp_bridge.py`。
> *   **通过标准**：在不启动旧版抓取脚本的情况下，通过 MCP 协议成功返回 $NVDA 的实时价格与财务摘要。

---

### 第二阶段：Orchestrator 升级 —— 混合 Agent 架构 (Research-Debate)
**目标**：重构 `AgentBridge` 逻辑，从“直接辩论”改为“调研-辩论”两步走。
*   **动作 1**：**分包调研 (Workers)**。Orchestrator 首先派发任务给三个专项子 Agent：数据提取、舆情收集、财务对账。
*   **动作 2**：**事实整合**。将分包调研结果汇总成一份《调研事实清单》，作为辩论的唯一参考。
*   **动作 3**：**博弈环节 (Thinkers)**。Bull vs Bear Agent 基于《事实清单》进行 1-2 轮深度辩论，Portfolio Manager 给出合规审计后的裁决。

> **🏁 验收节点 2：逻辑闭环验证**
> *   **验收方式**：触发一次深度分析并查看调试日志。
> *   **通过标准**：日志中清晰显示“Research Stage”成功产出事实列表，且“Debate Stage”中的 Agent 引用了调研出的具体数据。

---

### 第三阶段：Writer 升级 —— 动作化与自媒体分发
**目标**：产出多元化的“工业资产”，包括合规推文和结构化指令。
*   **动作 1**：**自媒体主笔**。新增 `WeChatWriter` 模块，产出带有合规性护栏（严禁承诺收益、自动免责声明）的公众号草稿。
*   **动作 2**：**动作导出 (Artifacts)**。Writer 在产出 Markdown 的同时，生成 `actionable_trade.json` 和一个基础的 `valuation_model.csv`。
*   **动作 3**：**对接 PM**。将生成的交易指令直接反馈给 `PortfolioManager` 的预挂单队列。

> **🏁 验收节点 3：资产产出验证**
> *   **验收方式**：检查 `reports/[SYMBOL]/` 目录。
> *   **通过标准**：目录下同时存在 `index.md` (内部), `wechat_post.md` (外部), `trade.json` (动作) 三类文件，且推文符合公众号排版规范。

---

### 第四阶段：Web UI 升级 —— 媒体中心与操作台
**目标**：前端适配新功能，提供“推文预览”与“指令确认”界面。
*   **动作 1**：**Media Center**。在 `ControlPanel.vue` 中增加“自媒体草稿库”，支持一键预览和复制推文 Markdown。
*   **动作 2**：**Action Dashboard**。在基金管理页面增加“待执行建议”模块，展示 AI 产出的 `trade.json` 内容，由用户点选“确认执行”。

> **🏁 验收节点 4：交互闭环验证**
> *   **验收方式**：在网页端点击“提取公众号草稿”。
> *   **通过标准**：弹窗正确显示经过排版优化的 Markdown 代码，且点击“复制”后能直接在 mdnice 等工具中完美还原。
