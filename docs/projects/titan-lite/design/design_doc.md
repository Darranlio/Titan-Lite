# 🏗️ Titan-Lite 核心技术架构与工程实现

欢迎阅读 **Titan-Lite** 高级量化与智能交易系统的核心技术文档。本手册不仅涵盖了系统的顶层设计，还详细记录了在低算力环境下实现高可用、工业级核算的工程细节。

---

## 1. 核心架构：认知博弈流水线 (Pipeline)

Titan-Lite 采用**分层式过滤架构**，在 2C2G 的算力限制下，实现了从“海选”到“精研”的资源最优化配置。

### 1.1 研判三部曲
1.  **Screener (初筛 - 数学过滤)**：利用 `yfinance` 抓取基本面数据（PE, ROE, Upside > 15%），将数千只标的快速压缩至 < 10 只。
2.  **FastFilter (快筛 - AI 闪电评分)**：调用 DeepSeek-Chat 对初筛结果进行 30 秒评分，确定优先级得分 (Priority Score)。
3.  **DeepDebate (精研 - 多智能体博弈)**：仅对得分 Top 3 的标的启动 `AgentBridge`。激活分析师团队（基本面、技术面、新闻、情绪）、博弈团队（多空对垒）以及终审层（风险管理+PM）。

---

## 2. 工程高可用：Solo Agent 降级机制

为了应对 API 配额限制（如 DeepSeek 429 错误）或网络波动，系统实现了一套自动降级策略：

*   **Standard Mode**：基于 `LangGraph` 的全量状态机运行，逻辑最严密，耗时 5-8 分钟。
*   **Solo Fallback (单兵模式)**：当检测到配额超限时，自动将上下文压缩并触发单次全量分析。
*   **价值**：确保系统在极端情况下依然能产生“有意义”的投研结论，而非直接崩溃。

---

## 3. 数据层：单位净值化核算引擎 (NAV Engine)

借鉴公募基金标准的**单位净值化 (Unitization)** 核算逻辑，彻底屏蔽入金/出金对收益率的干扰。

*   **核心公式**：`NAV = (持仓总市值 + 现金余额) / 总份额`。
*   **申购逻辑**：`申购份额 = 申购金额 / 当前 NAV`。
*   **一致性保证**：支持多币种（USD/HKD/CNY）实时汇率转换与交易撤销回滚，回滚后自动触发全账本重算。

---

## 4. 自动化工程细节

### 4.1 研讨档案馆 (Reports Vault)
*   **树状索引**：`reports/[SYMBOL]/index.md`是个股 Dashboard，`YYYY-MM-DD.md`是历史快照。
*   **翻译引擎**：集成了 LLM 自动将英文业务简介转化为专业的中文业务 DNA。

### 4.2 熔断器机制 (Circuit Breaker)
*   在策略启动前，系统会调用 `MacroRisk` 检查。若 VIX 恐慌指数过高或市场处于极端风险，系统将强制熔断，停止个股推荐并推送避险警报。
