# 🧠 Titan-Lite 策略研判逻辑 (V3.0)

## 1. 策略概览
Titan-Lite 不再是简单的指标回测系统，而是一个基于**认知博弈**的 AI 投研系统。其核心逻辑模仿了顶级对冲基金的投委会工作流程。

## 2. 三层过滤体系

### 第一层：估值初筛 (Screener)
- **目标**：从海量标的中找出“物美价廉”的潜在机会。
- **关键指标**：
  - **Upside > 15%**：基于分析师平均预期涨幅。
  - **PEG < 1.0**：确保增长与估值匹配。
  - **ROE > 15%**：筛选高效率的企业。

### 第二层：真伪鉴别 (Verification)
在 AI 介入之前，系统先进行物理层面的客观验证：
- **量价背离 (OBV)**：如果股价上涨但成交量加权重心下降，标记为“诱多风险”。
- **高管背离 (Insider)**：如果 AI 看多但高管在抛售，提示“言行不一”。

### 第三层：多智能体认知博弈 (Agent Debate)
这是系统的核心，通过四种专家角色进行全方位扫描：
1. **Market Analyst**：关注 MACD, RSI, 均线支撑等技术面。
2. **Fundamentals Analyst**：深挖资产负债表、FCF（自由现金流）和净利润率。
3. **Sentiment Analyst**：扫描社交媒体情绪，判断是否过度拥挤。
4. **News Analyst**：分析宏观新闻与地缘政治对行业的冲击。

## 3. 核心算法应用

### 3.1 对冲博弈模型 (Bull/Bear Debate)
- **机制**：系统强制让两个 Agent 分别扮演“死多头”和“死空头”。
- **目的**：打破 LLM 常见的“复读机”倾向（Confirmation Bias），通过辩论逼出最核心的风险点。

### 3.2 最终判决逻辑 (Portfolio Manager)
- **决策权重**：PM 会根据辩论的证据质量（Evidence Quality）而非音量来决定最终评级。
- **输出格式**：Buy (买入), Overweight (增持), Hold (持有), Underweight (减持), Sell (卖出)。

## 4. 💡 投资知识点 (Learning Points)
- **PEG 指标**：市盈率相对盈利增长比率。DeepSeek 在研报中会专门注释：`PEG < 1 意味着你正在以低于其增长速度的价格购买一家公司的股票，具有安全边际。`
- **OBV 背离**：能量潮指标。如果价格创新高而 OBV 未创新高，意味着上涨动力枯竭。
