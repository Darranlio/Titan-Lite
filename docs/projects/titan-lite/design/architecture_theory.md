# 🏛️ Titan-Lite 核心原理与设计哲学

## 1. 系统愿景
Titan-Lite 旨在为个人投资者提供一个运行在低配云服务器（2C2G）上的“机构级”投研终端。其核心理念是：**通过多智能体博弈模拟人类精英投委会的思考过程，辅以数学模型的客观验证，实现认知的降维打击。**

---

## 2. 核心理论模型

### 2.1 认知博弈论 (Multi-Agent Debate)
- **原理**：LLM 往往存在“确认偏误”（Confirmation Bias）。为了解决这一问题，系统强制启动 **Bull Agent（死多头）** 与 **Bear Agent（死空头）** 的对垒。
- **机制**：通过 DeepSeek 强大的推理链，两名 Agent 必须基于真实财务数据和技术面信号进行三轮博弈。
- **结果**：由 **Portfolio Manager（首席审计官）** 进行最终裁决，剥离情绪泡沫，挖掘最真实的投资逻辑。

### 2.2 分级研判哲学 (Tiered Analysis)
- **背景**：深度分析单只个股耗时约 10 分钟。全市场扫描几十只标的时，资源和时间消耗巨大。
- **方案**：
    1. **Screener (初筛)**：基于估值（Upside > 15%, PE, ROE）的数学物理过滤。
    2. **Fast Filter (快筛)**：AI 闪电打分（30秒），确定优先级。
    3. **Deep Debate (深研)**：仅对 Top 3 进行全量 Agent 辩论。
- **意义**：在有限的算力下实现最大的覆盖广度与深度平衡。

### 2.3 鉴伪验证层 (Verification Layer)
- **量价共振 (OBV)**：价格上涨必须有资金流入支撑。若价格创新高而 OBV 未创新高，判定为“诱多”。
- **言行一致 (Insider)**：监控高管减持行为。若 AI 看多但高管在抛售，发出红色风险预警。
- **事实核查 (News Check)**：利用 LLM 交叉比对多源新闻，过滤“带节奏”的软文。

---

## 3. 基金管理逻辑：单位净值化
- **单位净值 (NAV)**：借鉴公募基金核算逻辑。`NAV = (持仓市值 + 现金) / 总份额`。
- **意义**：屏蔽本金变动（入金/出金）对收益率的干扰，真实记录投资者的“选股与择时”水平。
- **风险归因**：计算 **夏普比率 (Sharpe)** 和 **最大回撤 (MDD)**，量化投资组合的健康度。

## 4. 数字化档案馆
- **树状存储**：摒弃平铺式文件管理，按 `[Symbol]/[Date]` 建立时空索引。
- **动态 Dashboard**：不仅仅是结果的展示，更是个股基本面演变的“活化石”。
